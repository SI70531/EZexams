Algorithm 3-18　Append linked lists

Analysis (steps): 1. if the first list is null, set its head pointer to the head pointer of the second list; 2. traverse the first list to find the last node; 3. change the last node's link pointer to point to the beginning of the second list; 4. add the counts for the two lists and place the sum in the count for the first list.分析（步驟）：1. 第一個串列是空的，就把它的 head 設成第二個串列的 head；2. 走訪第一個串列找到最後一個節點；3. 把最後一個節點的 link 改指第二個串列的開頭；4. 兩個 count 相加，存到第一個串列的 count。

4-1 Basic Stack Operations ★★★堆疊的基本運算

What a stack is Slide 3 to 4什麼是堆疊

  • A stack is a linear list in which all additions and deletions are restricted to one end, called the top.堆疊是一種線性串列，所有新增和刪除都只能在同一端進行，這一端叫做 top（頂端）。
  • LIFO (last in, first out): data input as {5, 10, 15, 20} are removed as {20, 15, 10, 5}.後進先出：依序放入 5、10、15、20，取出的順序是 20、15、10、5。
  • In Ch3's terms a stack is a restricted list, so traversal does not apply to it.用 Ch3 的說法，stack 是受限串列（restricted list），所以不能做 traversal（走訪）。
In plain wordsThink of a pile of plates: you can only put a plate on the top and take the top plate off. The plate you put on last is the first one you take.白話 想像一疊盤子：只能把盤子放在最上面、也只能拿最上面那個。最後放上去的，最先被拿走。

Chapter summarySummary 本章總結
  • A stack is a linear list where all additions and deletions happen at one end, the top: LIFO.堆疊是只能在頂端新增、刪除的線性串列：後進先出。
  • Three basic operations: push (overflow if no room), pop (underflow if empty), stack top (returns the top without deleting; underflow if empty).三個基本運算：push（沒空間會 overflow）、pop（空的會 underflow）、stack top（回傳頂端但不刪除；空的會 underflow）。

  • Four application types: reversing (reverse a list, decimal to binary), parsing (parentheses), postponement (infix to postfix, evaluating postfix), backtracking (goal seeking, eight queens).四類應用：反轉（反轉數列、十進位轉二進位）、剖析（括號配對）、延後（中序轉後序、計算後序式）、回溯（找目標、八皇后）。

  • pushStack: newPtr->next = stack.top must come before stack.top = newPtr.pushStack：newPtr->next = stack.top 一定要在 stack.top = newPtr 之前。
  • popStack: save dltPtr = stack.top before moving top, or the node cannot be recycled.popStack：移動 top 之前先存 dltPtr = stack.top，否則節點無法回收。
  • Infix to postfix pops on lower or equal priority (≤), not only lower: A − B + C → A B − C +.中序轉後序遇到「小於或等於」就要 pop，不是只有小於：A − B + C → A B − C +。
