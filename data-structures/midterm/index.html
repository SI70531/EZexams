Pseudocode example: Algorithm 1-2 Slide 15–16虛擬碼範例：Algorithm 1-2

algorithm deviation
   Pre    nothing
   Post   average and numbers with their deviation printed
1 i = 0
2 loop (not end of file)
  1 read number into array[i]
  2 sum = sum + number
  3 i = i + 1
3 end loop
4 average = sum / i
5 print (average)
6 j = 0
7 loop (j < i)
  1 devFromAve = array[j] - average
  2 print (array[j], devFromAve)
  3 j = j + 1
8 end loop
9 return
end deviation
Algorithm 1-2　Print deviation from mean for series of numbers

What it does: the first loop reads the numbers in the file into array[i] one by one while summing; after reading, i is exactly how many numbers were read, so average = sum / i. The second loop runs from j = 0 to j < i, printing each number and how far it is from the average (the deviation).這段在做什麼：第一個 loop 把檔案裡的數字一個個讀進 array[i]，同時加總；讀完 i 剛好是讀了幾個數，所以 average = sum / i。第二個 loop 從 j = 0 跑到 j < i，印出每個數和它離平均多遠（deviation）。

Algorithm 1-2 analysis (the three points on slide 16):Algorithm 1-2 analysis（投影片 16 的三點）：

  2. This uses code-oriented pseudocode (close to real code, i = i + 1) rather than “tight English” pseudocode (plain English, Add one to i).這裡用的是偏程式的寫法（code-oriented pseudocode，i = i + 1），而不是純英文寫法（tight English pseudocode，Add one to i）。

Example of an ADT: a bank queue slides 24–25ADT 範例：銀行排隊

  • A systems analyst must simulate the waiting line of a bank, which calls for a queue model.系統分析師要模擬銀行的排隊等候線，需要一個 queue。

Folding method Slide 62–64 ★★★摺疊法

  • 兩種：fold shift 和 fold boundary。
  • Fold shift: the key value is divided into parts whose size matches the size of the required address (cut into pieces as long as the address), the left and right parts are shifted and added with the middle part (the left and right pieces are slid over and added to the middle one).Fold shift（移位摺疊）：把 key 切成和位址一樣長的幾段，左右兩段直接移過來，和中間那段相加。

Why collision resolution is needed slides 76–77為什麼需要解決碰撞

Concept 1 of 3: Load factor slide 78 ★★★概念 1／3：負載因子（投影片 78）

The higher the load factor, the easier it is to collide.α = (k / n) × 100，k 是已填的格數，n 是總格數。例：19 格放了 9 個，9/19 × 100 ≈ 47%。Load factor 越高，越容易碰撞。

Concept 2 of 3: Clustering slides 79–80 ★★★概念 2／3：聚集（clustering）（投影片 79–80）

  • Clustering: the tendency of data to build up unevenly across a hashed list (data piles up unevenly in some places).Clustering（群集）：資料不平均地堆在雜湊表的某些地方。
  • Clustering: the number of probes to locate an element grows,reduces the processing efficiency of the list.聚集嚴重時：找到一個元素所需的探測次數增加，降低串列的處理效率。
  • Primary clustering: occurs when data cluster around a home address, easy to identify (one region is obviously full).Primary clustering（主要群集）：資料聚在某個 home address 附近，很容易辨認（某一區明顯塞滿）。
  • Secondary clustering: occurs when data become grouped along a collision path throughout a list, not easy to identify (data is spread over the whole table, but all on the same collision path).Secondary clustering（次要群集）：資料沿著同一條碰撞路徑散布在整張表上，不容易辨認。
  • Goal:design hashing algorithm to minimize clustering.目標：設計雜湊演算法，讓碰撞群集（clustering）降到最低。

Concept 3 of 3: put an upper limit on the number of elements checked slide 81概念 3／3：限制檢查的元素數量上限

  • Number of elements examined for a place to store the data must be limited.檢查可以存放資料的位置時，要有數量上限。
  • The traditional approach “check until every element has been seen” has problems: the search is not sequential (reaching the “last cell” does not mean every cell was checked); examining every element would be time-consuming; and some of the collision resolution techniques cannot physically examine all of the elements (e.g., quadratic probe can never reach some cells, see Table 2-2).「檢查到所有元素都看過」這個傳統做法有問題：搜尋路徑不是循序的，走到最後一格不代表每格都檢查過；檢查每個元素很耗時；而且有些碰撞解決技術實際上走不到所有格子（例如 quadratic probe，見表 2-2）。

  • A major disadvantage to open addressing: each collision resolution increases the probability of future collision (this is how C in Figure 2-7 got dragged in).Open addressing 的一大缺點：每解決一次碰撞，之後再碰撞的機率就增加（圖 2-7 的 C 就是這樣被連累的）。

Insert node: three steps slide 26 ★★★插入節點：三個步驟

Insert node adds data to a linked list. Three steps to the insertion:插入節點就是把資料加進鏈結串列。三個步驟：

  1. Allocate memory for the new node and insert data.配置新節點的記憶體並放入資料。
  2. Point the new node to its successor.讓新節點指向它的後繼節點。
  3. Point the new node’s predecessor to the new node.讓新節點的前驅節點指向新節點。

Two states of the node that precedes the new node: the predecessor is null or not null. The four insertion cases (empty, beginning, middle, end) boil down to just these two ways of writing it.新節點前面那個節點的狀態只有兩種：前驅節點是 null，或不是 null。四種插入情況（空串列、最前面、中間、最後面）最後只剩這兩種寫法。

Insert into empty list Slide 27–28插入空串列

Set the link of the new node to a null pointer,assign the list head pointer the address of new node.把新節點的 link 設成 null，再把串列的 head 指向新節點。

pNew->link = list.head        Set link to null pointer
list.head  = pNew             Point list to first node

Note the order of these two statements: must first point the new node to its successor, then change the head pointer. (In an empty list list.head is null, so the first line amounts to setting pNew->link to null.)注意這兩行的順序：必須先讓新節點指向後繼節點，再改 head 指標。（空串列時 list.head 是 null，所以第一行等於把 pNew->link 設為 null。）

Insert in middle Slide 31–32插在中間

To insert a node between two nodes, we point the new node to its successor, then point its predecessor to the new node. The address of the new node’s successor can be found in the predecessor’s link field.要把節點插在兩個節點之間，先讓新節點指向後繼節點，再讓前驅節點指向新節點。新節點的後繼位址可以從前驅節點的 link 欄位找到。

Insert at end Slide 33–34插在結尾

Only point the predecessor to the new node:只需要讓前驅節點指向新節點：

pNew->link = null pointer
pPre->link = pNew

pNew->link = pPre->link
pPre->link = pNew

Ch2 Searching（搜尋）

2-1

List Searches（串列搜尋）

  • Sequential search: for unsorted, small, rarely searched lists; four parameters list, last, target, ref locn; O(n).Sequential search：沒排序、小、不常搜尋的 list 用；四個參數 list、last、target、ref locn；O(n)。
  • Sentinel search reduces the loop's two conditions to one (Knuth). Probability search swaps the found element forward during the search.Sentinel search 把迴圈的兩個條件減成一個（Knuth）。Probability search 會在搜尋時把找到的元素往前換。
  • Ordered list search: stop when target ≤ the current element; no need to search to the end.Ordered list search：target ≤ 目前元素就停，不用找到底。
  • Binary search stops when found, or first > last. For 1024 elements the answer is 10.Binary search 停止：找到，或 first > last。1024 個元素答 10。
2-2

Hashed List Searches（雜湊搜尋）

  • Goal: find it with just one comparison; hashing = key-to-address transformation.目標：只比一次就找到；hashing＝key-to-address transformation。
  • Terms: synonyms (keys that hash to the same location), collision (location already taken), home address, prime area, probe (each address computation and test).名詞：synonyms（hash 到同一位置的 keys）、collision（位置被佔）、home address、prime area、probe（每算一次地址並測試）。
  • Direct hashing: no synonyms, no collisions. Modulo-division: uses the remainder, works with any list size, a prime is preferred.Direct hashing：no synonyms, no collisions。Modulo-division：用餘數，任何 list size 都能用，偏好質數。
  • Others: subtraction, digit extraction (take certain digits), midsquare (square, take the middle), fold shift/boundary, rotation (move the last digit to the front), pseudorandom (y = ax + c, then MOD).其他：subtraction、digit extraction（取第幾位）、midsquare（平方取中）、fold shift／boundary、rotation（最後一位轉到最前）、pseudorandom（y = ax + c 再 MOD）。

  • Open addressing：linear probe、quadratic probe、double hashing（pseudorandom）、key offset。Chaining 不是。
  • Clustering：linear probe → primary clustering；secondary clustering 沿著 collision path，用 key offset 減少。
  • Bucket hashing 的問題：more space；does not completely resolve collisions。

3-1

Linear List Concepts（線性串列）

  • Arrays are easy to build and use, but insertion and deletion require moving data; linked lists insert and delete quickly, but search and retrieval are inefficient.Array 好建好用但插入刪除要搬資料；linked list 插入刪除快但 search、retrieval 沒效率。

Linked List Concepts（鏈結串列觀念）

  • 每個 node 至少 data ＋ link；self-referential structure。
  • Nodes are not contiguous in memory (no physical relationship) → binary search is impossible. Empty list: head is null.節點在記憶體不連續（no physical relationship）→ 不能用 binary search。Empty list：head 是 null。
  • The head structure holds metadata (count, pos, head); pLoc = current node, pPre = previous node.head structure 放 metadata（count、pos、head）；pLoc＝目前節點、pPre＝前一個。
  • Not always necessary but improves efficiency → rear pointer。
3-3

Linked List Algorithms (the ten basic algorithms) ★★★

  • insertNode order: first pNew->link, then change head or pPre->link (link the later node first, then change the earlier one, or the later nodes get lost).insertNode 順序：先 pNew->link，再改 head 或 pPre->link（先接後面再改前面，不然會弄丟後面的節點）。
  • Insert has four cases (empty, beginning, middle, end) → two logics: pPre is null / is not null; overflow returns false.insert 四情況（empty、beginning、middle、end）→ 兩種邏輯：pPre 是 null／不是 null；overflow 回傳 false。
  • The four delete cases → two: delete the first, delete any other; pLoc must already be found before the call.delete 四情況 → 兩種：刪第一個、刪其他；pLoc 呼叫前就要先找到。
  • searchList six-result table: pLoc stops at the first node ≥ target; if all are smaller → pPre = last node, pLoc = null.searchList 六種結果表：pLoc 停在第一個 ≥ target 的節點；全部都比較小 → pPre = last node、pLoc = null。
  • How to test full list → allocate memory and see if it succeeds。

insertNode

if (pPre null) pNew->link = list.head list.head = pNew else pNew->link = pPre->link pPre->link = pNew list.count = list.count + 1

deleteNode

dataOut = pLoc->data if (pPre null) list.head = pLoc->link else pPre->link = pLoc->link list.count = list.count - 1 recycle (pLoc)

searchList

pPre = null pLoc = list.head loop (pLoc not null AND target > pLoc->data.key) pPre = pLoc pLoc = pLoc->link found = (pLoc not null AND target equal pLoc->data.key)

destroyList

loop (list.count not zero) dltPtr = list.head list.head = dltPtr->link list.count = list.count - 1 recycle (dltPtr) list.pos = null
