Chapter 1

Ch1 Introduction（導論）

Pseudocode（虛擬碼）、ADT（抽象資料型態）、Big-O（效率）。考試大多是觀念選擇題，加上 loop 次數與 Big-O 計算。讀完做最下面的選擇題和手寫練習。

1-1 Pseudocode（虛擬碼）

Pseudocode 是 an English-like representation of the code（類似英文的程式表示法），一半英文、一半 structured code（結構化程式碼）。

Algorithm header（演算法標頭） ★★★

每個演算法開頭都有 header，寫出名稱、參數、前後條件。使用演算法的程式設計師通常只看 header，所以 header 要寫得夠完整。

Algorithm search (val list   <array>,
                  val argument <integer>,
                  ref location <index>)
Search array for specific item and return index location.
   Pre    list contains data array to be searched
          argument contains data to be located in list
   Post   location contains matching index
          -or- location of last element if not found
   Return true if found, false if not found
欄位意思一句話記法
Purpose（目的）A short statement about what the algorithm does這演算法在幹嘛
Precondition（前置條件）Lists any precursor requirements for the parameters。沒有也要寫 Pre nothing開始前參數要滿足什麼
Postcondition（後置條件）Identifies any action taken and the status of any output parameters做完後輸出的狀態
Return condition（回傳條件）If a value is returned, it is identified here回傳什麼

Output parameter vs. return value：output parameter 用 ref（pass by reference，傳參考）把結果寫回呼叫者，可以有很多個；return value 只有一個，由 return 回傳。val 是 pass by value（傳值）。

Statement numbers 與三種結構 ★★★

敘述有編號，像 3.1 是第 3 行底下展開的第 1 行。任何演算法都只要三種 construct（結構）就能寫出來：

Sequence（循序）
A series of statements that do not alter the execution path（不會改變執行路徑）。
Selection（選擇）
Evaluate one or more alternatives，例如 if / else。
Loop（迴圈）
Iterates a block of code，pseudocode 的 loop 就像 while loop。
考古題陷阱：「A sequence changes how the algorithm runs」是錯的。

Variables（變數命名）

  • 要用 intelligent data names（有意義的名稱），描述資料的意義。
  • 不要用 single character names（單一字元，如 i、x）。
  • 不要用 generic names（通用名稱）：count、sum、total、row、column、file。
  • 縮寫可以：numOfStu 是好名稱，noStu 不好。
  • Pseudocode 的 array 從 index 0 開始。

1-2 The Abstract Data Type（抽象資料型態）

  • Spaghetti code（義大利麵程式碼）：nonstructural, linear programs，沒有結構。
  • Modular programming（模組化程式設計）：程式分成 functions。Structured programming 的觀念是 1970 年代建立的。
  • Object-oriented programming（物件導向）：functions 圍繞一個 object 開發（例如 linked list）。
  • Encapsulation（封裝）：all processing for an object is bundled together in a library and hidden from the user。

資料的分類 ★★★

名詞定義例子
Data type（資料型態）兩部分：a set of data ＋ the operations on the datainteger 與 + − × ÷
Atomic data（原子資料）Single, nondecomposable entity（不可再分）integer、floating point、character
Composite data（複合資料）可以拆成有意義的部分telephone number = area code ＋ exchange ＋ number
Data structure（資料結構）An aggregation of atomic and composite data types into a set with defined relationshipsarray、record

Abstract Data Type, ADT（抽象資料型態） ★★★

  • 使用者只在乎 what it can do（能做什麼），不在乎 how the task is done（怎麼做）。
  • ADT 是一組定義，讓程式設計師使用功能，同時隱藏實作（hiding the implementation）＝ Abstraction（抽象化）。
  • 一個 list 放進 ADT 後，使用者不該知道底層是 array、linked list 還是其他結構。
  • Formal definition：A data declaration packaged together with the operations that are meaningful for the data type。
銀行排隊例子（ADT 的好處） 系統分析師要模擬銀行排隊，需要 queue 和 enqueue / dequeue。兩種做法：(1) 寫一個專用的模擬程式，只能用在這個應用；(2) 寫一個 queue ADT，任何 queue 問題都能用。選 (2) 後，模擬程式還是要寫，但分析師可以專心在應用本身，不用管 queue。

1-3 A Model for an ADT（ADT 模型）

  • 模型裡有兩樣東西：data structure 和 operational functions，兩者都在模型內，都不在使用者的範圍內（not within the user’s scope）。
  • 資料透過 operational interfaces（操作介面）來新增、存取、修改、刪除。使用者只看得到 operation name and its parameters。
  • Pointer to a hidden structure（指向隱藏結構的指標）：使用者拿到的是一個指標，看不到結構內容。
  • ADT class templates：資料結構用 template identifier TYPE，key 型態用 KTYPE（optional）。Program 1-2 的例子：structure 叫 PICTURE，key 是得獎年份，key type 是 short。

Algorithmics：systematic study of fundamental techniques used to design and analyze efficient algorithms。效率分析重點在 loops，用 f(n) 表示（n = 要處理的元素數）。

Logarithmic loop 怎麼數：n = 1000 時，i = 1, 2, 4, …, 512 共 10 次，約 log₂1000 ≈ 10。

數 loop 次數的三個步驟
  1. 看控制變數怎麼變：+1、+2（加減）→ linear；*2、/2（乘除）→ logarithmic。
  2. 乘除的 loop 列出來數：i = i * 2 時 i 是 1, 2, 4, 8, …，找最大的 2ᵏ 還滿足條件，次數 = k + 1。例：i < 1000 → 2⁹ = 512 是最後一個 → 10 次。i = i / 2 從 1000 往下：1000, 500, 250, 125, 62, 31, 15, 7, 3, 1 → 也是 10 次。
  3. 巢狀 loop：內層次數固定（不看外層變數）就直接相乘；內層上限是外層變數（如 j <= i）就是 dependent，要把每一圈加起來。
Linear logarithmic 的樣子：外層 n 次 × 內層 log₂n 次
1 i = 1
2 loop (i <= n)
  1 j = 1
  2 loop (j <= n)
    1 application code
    2 j = j * 2
  3 end loop
  4 i = i + 1
3 end loop                          f(n) = n log₂n
ANSWER TEMPLATEThe outer loop is a linear loop and runs n times. The inner loop is a logarithmic loop and runs log₂n times. The total is f(n) = n log₂n, so the efficiency is O(n log n).
中文外層是線性迴圈，跑 n 次；內層是對數迴圈，跑 log₂n 次。總次數 f(n) = n log₂n，所以效率是 O(n log n)。數字換成題目的就能直接用。

Big-O Notation（大 O 表示法）推導兩步驟

  1. In each term, set the coefficient of the term to 1（每一項的係數設成 1）。
  2. Keep the largest term and discard the others（只留最大項，其他丟掉）。
f(n) = n(n+1)/2 = ½n² + ½n
  步驟 1 → n² + n
  步驟 2 → n²         ⇒ O(n²)

f(n) = aⱼnᵏ + aⱼ₋₁nᵏ⁻¹ + … + a₁n + a₀  ⇒ O(nᵏ)

Ch2 Searching（搜尋）

Sequential／binary search 和三種變形、八種 hashing method、collision resolution。雜湊計算是 Part III 最大題，一定要會算。

2-1 List Searches（串列搜尋）

Sequential search（循序搜尋）

  • 用在 list not ordered（沒排序）、small lists、not searched often 的情況。
  • 兩種結果：find it，或 reach the end of the list。
  • 要告訴呼叫者兩件事：有沒有找到、在哪個 index。
  • 四個參數：the list、an index to the last element、the target、the address（找到的位置，用 ref）。
  • 效率 O(n)。
Algorithm seqSearch (val list <array>, val last <index>,
                     val target <keyType>, ref locn <index>)
1 looker = 0
2 loop (looker < last AND target not equal list[looker])
  1 looker = looker + 1
3 end loop
4 locn = looker
5 if (target equal list[looker])
  1 found = true
6 else
  1 found = false
7 end if
8 return found
end seqSearch

三種變形 Variations ★★★

方法做法重點
Sentinel search（哨兵搜尋）在 array 尾端加一格 sentinel，把 target 放進去，保證一定找得到迴圈原本測兩個條件（end of list、target not found），現在只測一個。Knuth：「When the inner loop tests two or more conditions, reduce it to just one.」
Probability search（機率搜尋）最常被找的放前面；每次找到就和前一個元素交換適合 few elements are the targets for most of the searches。搜尋過程會重新排列元素
Ordered list search（有序串列搜尋）不用找到底，當 target ≤ current element 就停小的有序 list 用這個可能比 binary search 還快
Sentinel search 的核心（和 seqSearch 比：迴圈條件少了 looker < last）
1 list[last + 1] = target           放哨兵：保證一定找得到
2 looker = 0
3 loop (target not equal list[looker])
  1 looker = looker + 1
4 end loop
5 if (looker <= last)               停在真正的資料裡 → 找到
  1 found = true
6 else                              停在哨兵 last + 1 → 原本的 list 裡沒有
  1 found = false
7 end if
8 locn = looker
Probability search 例子
[A, B, C, D, E] 找 D：找到後 D 和前一個 C 交換 → [A, B, D, C, E]。再找一次 D → 和 B 交換 → [A, D, B, C, E]。常被找的會一格一格往前移，下次比較快找到。
Ordered list search 例子
[3, 8, 12, 20, 31] 找 10：比 3（10 > 3）、比 8（10 > 8）、比 12（10 ≤ 12）→ 停。12 不等於 10 → 找不到。只比了 3 次，不用比到 31。

Binary search（二元搜尋） ★★★

  • 前提：list 必須 sorted（已排序），而且是 array。元素超過 16 個時就考慮用。
  • 三個變數：first、mid、last。mid = (first + last) / 2（無條件捨去）。
  • 停止條件：target is found，或 first becomes larger than last（first > last，代表找不到）。
  • 每次砍掉一半 → logarithmic loop → O(log n)。
Algorithm binarySearch (val list <array>, val last <index>,
                        val target <keyType>, ref locn <index>)
1 first = 0
2 last  = last
3 loop (first <= last)
  1 mid = (first + last) / 2
  2 if (target > list[mid])
    1 first = mid + 1          look in upper half
  3 elseif (target < list[mid])
    1 last = mid - 1           look in lower half
  4 else
    1 first = last + 1         found: force exit
  5 end if
4 end loop
5 locn = mid
6 if (target equal list[mid]) found = true
7 else found = false
8 return found
end binarySearch

2-2 Hashed List Searches（雜湊搜尋）

目標：to find the data with only one test（只比一次就找到）。Hashing 是 key-to-address transformation（把 key 轉成地址）。

名詞意思
Synonyms（同義字）The set of keys that hash to the same location
Collision（碰撞）算出來的地址已經被佔用了
Home address（本位地址）The address produced by the hashing algorithm
Prime area（主要區）The memory that contains all of the home addresses
Probe（探測）Each calculation of an address and test for success

搜尋時用跟插入時同一個 hashing 演算法；home address 不是要找的資料，就用 collision resolution 算下一個位置。

Hashing methods（雜湊方法）八種 ★★★

方法做法例子
Direct（直接）key 就是地址，不做運算。保證 no synonyms, no collisions，但能用的情況有限一個月的日期當 key；員工編號 1–100
Subtraction（減法）key 連續但不從 1 開始，減掉一個數員工編號 1001–1100 → 減 1000
Modulo-division（除法取餘）address = key MOD listSize。任何 list size 都能用，size 用質數碰撞較少121267 MOD 307 = 2
Digit extraction（數字抽取）取 key 的特定幾位當地址379452 取第 1、3、4 位 → 394
Midsquare（平方取中）key 平方後取中間幾位。限制：key 太大平方會太大9452² = 89340304 → 3403；變形：379452 取 379，379² = 143641 → 364
Fold shift（摺疊移位）key 切成和地址一樣長的幾段，直接相加123|456|789 → 123+456+789 = 1368 → 去掉進位 → 368
Fold boundary（摺疊邊界）左右兩段反轉後再加321+456+987 = 1764 → 764
Rotation（旋轉）把最後一個字元轉到最前面，key 是 serial（連號）時最有用，常和 folding 一起用600101 → 160010；fold shift 成兩位：16+00+10 = 26
Pseudorandom（虛擬亂數）key 當 seed：y = ax + c，再 MOD listSize。a、c 最好是質數a=17, c=7：17×121267+7 = 2061546，MOD 307 = 41

2-3 Collision Resolution（碰撞處理）

三個概念

  • Load factor（負載因子）：α = (k / n) × 100。k = 已填的元素數，n = 總格數。例：19 格放 9 個 → 9/19 ≈ 47%。
  • Clustering（叢集）：資料不平均地堆在一起，probe 次數變多、效率變差。
    • Primary clustering（主要叢集）：data cluster around a home address，容易看出來。
    • Secondary clustering（次要叢集）：data become grouped along a collision path，不容易看出來。
  • 找空位時檢查的元素數量必須有上限。

Open addressing（開放定址，在 prime area 內解決） ★★★

方法下一個地址優缺點
Linear probe（線性探測）舊地址 + 1簡單、資料靠近 home address；缺點：primary clustering
Quadratic probe（平方探測）舊地址 + (probe 次數)²，即 +1, +4, +9, …要算平方較花時間；list size 100 時只有 59 個地址探得到
Pseudorandom（double hashing）用碰撞地址當 x 算 y = ax + c限制：所有 key 走同一條 collision path
Key offset（double hashing）offset = key / listSize（取商）
新地址 = (offset + 舊地址) MOD listSize		不同 key 走不同的 collision path → 減少 secondary clustering
四種 open addressing 的公式（考試直接套）
方法第 i 次 probe 的地址
Linear probe(前一個地址 + 1) MOD listSize：超過最後一格就繞回 0
Quadratic probe(前一個地址 + i²) MOD listSize：依序 +1、+4、+9、+16…
Pseudorandom(a × 前一個地址 + c) MOD listSize
Key offset(offset + 前一個地址) MOD listSize，offset = key ÷ listSize 取商
例：list size 17，home 5，quadratic 連撞三次：5 → 6 (+1) → 10 (+4) → 19 MOD 17 = 2 (+9)。忘記 MOD 就會寫成 19。
碰撞次數怎麼算每 probe 到一個已經有人的格子就算 1 次 collision。第一次算出 home address 就是空的 → 0 次。例：home 8 有人、9 有人、10 有人、11 空 → 這個 key 碰撞 3 次，最後放 11。題目問「總共幾次」就把每個 key 的次數加起來。
先摺疊再算 key offset題目寫「fold boundary … then modulo division of the folded sum」時，後面的 key offset 也用摺疊後的數字去除。例：234554 摺疊後是 122，list size 19：home = 122 MOD 19 = 8，offset = 122 ÷ 19 = 6，probe 1 = (6 + 8) MOD 19 = 14。用原本的 6 位數 key 去除會被扣分。

Linked list resolution（鏈結串列處理）

  • Open addressing 的缺點：每次碰撞處理都會提高之後碰撞的機率。
  • 用兩塊空間：prime area 和 overflow area，碰撞的資料串在 home address 後面。
  • 串的順序：最常用 LIFO（Last In, First Out，後進先出：新的放 overflow list 最前面），或 key sequence（依 key 排序）。
  • 這個方法也叫 chaining（串接）。它不屬於 open addressing，因為碰撞的資料放到 prime area 外面去了。考古題選項「linear probe, quadratic probe, double hashing, and chaining」就是錯在 chaining。
例子：list size 11，27 和 16 的 home address 都是 5。27 先放在 prime area 的 5；16 來了撞到，就放進 overflow area，5 號格子多一個 link 指向它：[5] 27 → 16 → null。之後再有 home 5 的 key，用 LIFO 就插在 27 後面的第一個位置。

Bucket hashing（桶雜湊）

每個地址是一個 bucket，可放多筆資料，collision 延後到 bucket 滿才發生。兩個問題：用更多空間；沒有完全解決碰撞。

例：每個 bucket 放 3 筆，home 5 的 key 前三個都直接放進 bucket 5，第四個來才算碰撞，要再用其他方法（例如 linear probe 到 bucket 6）。

Combination approaches

大型系統會組合：先 hash 到 bucket，滿了做固定次數的 linear probe，再用 linked list overflow area。

3-1 Linear List Concepts（線性串列）

Array 好建好用，但插入刪除要搬資料很沒效率；linked list 插入刪除很快，但 search 和 retrieval 沒效率。

類型說明
General list（一般串列）任何位置都能插入刪除。分 random list（無排序）和 ordered list（依 key 排序）
Restricted list（受限串列）只能在兩端加入刪除。FIFO（First In, First Out，先進先出）= queue（佇列），像排隊買票；LIFO（Last In, First Out，後進先出）= stack（堆疊），像疊盤子，最後放上去的最先拿走

四種操作：Insertion、Deletion、Retrieval（三種所有 list 都適用）、Traversal（restricted list 不適用）。

  • Deletion：先 search 找到資料。Array 刪除後要把後面的資料往前搬，linked list 不用。
  • Retrieval：找到資料交給呼叫模組，不改變 list 內容。
  • Traversal：retrieval 的特例，所有元素依序處理，用 looping algorithm 而不是 search。

3-2 Linked List Concepts（鏈結串列觀念）

  • An ordered collection of data，每個元素包含下一個元素的位置。
  • 每個 node（節點）至少兩個欄位：data 和 link。
  • Singly linked list（單向鏈結）：只有一個 link 指向 successor（後繼）。
  • Self-referential structure（自我參考結構）：結構裡有指向同型態結構的指標。
  • 節點在記憶體中不連續（no physical relationship），所以不能用 binary search。
  • Empty linked list：head pointer 是 null。

資料結構與指標

   count  <integer>                    data  <dataType>   含 key 欄位
   pos    <node pointer>               link  <node pointer>
   head   <node pointer>
end list                            end node
指標意思
pHead / list.headHead pointer，指向第一個 logical node
Metadata（後設資料）Data about the list，例如 count，存在 head structure

3-3 Linked List Algorithms（十個基本演算法） ★★★

insertNode（2025 考過）

三步驟：(1) allocate memory for the new node and insert data；(2) point the new node to its successor；(3) point the predecessor to the new node。順序很重要：先接後面，再改前面，否則會弄丟後面的節點。

四種情況：insert into empty list、at beginning、in middle、at end。前兩種邏輯一樣（pPre 是 null），後兩種邏輯一樣。

Algorithm insertNode (ref list <metadata>, val pPre <node pointer>,
                      val dataIn <dataType>)
1 allocate (pNew)
2 if (memory overflow)
  1 return false
3 end if
4 pNew->data = dataIn
5 if (pPre null)                  adding before first node or to empty list
  1 pNew->link = list.head
  2 list.head = pNew
6 else                             adding in middle or at end
  1 pNew->link = pPre->link
  2 pPre->link = pNew
7 end if
8 list.count = list.count + 1
9 return true
end insertNode

Overflow（記憶體用完）時回傳 false，讓呼叫模組決定要中止還是做其他處理。

deleteNode

步驟：找到要刪的節點 → 讓 predecessor 指向 successor → 從 dynamic memory 回收。四種情況（only node、first、middle、last）簡化成兩種：delete the first node 和 delete any other node。要刪的節點由 pLoc 指定，在呼叫前就要先找到。

Algorithm deleteNode (ref list <metadata>, val pPre <node pointer>,
                      val pLoc <node pointer>, ref dataOut <dataType>)
1 dataOut = pLoc->data
2 if (pPre null)                  deleting first node
  1 list.head = pLoc->link
3 else                             deleting other nodes
  1 pPre->link = pLoc->link
4 end if
5 list.count = list.count - 1
6 recycle (pLoc)
end deleteNode

Recycle 放在 if 外面，因為兩邊都要做。刪除唯一節點時，pLoc->link 是 null，所以 head 自動變 null。

白話：刪除只是「讓前一個節點跳過它」。跳過之後一定要 recycle 把記憶體還給系統，並把 count 減 1；少了任何一步，串列看起來對，但記憶體沒還、節點數也錯了。

searchList（Ordered list search） ★★★

Linked list 只能用 sequential search。回傳兩個位置：找到時的位置，或找不到時「應該插入的位置」。

Algorithm searchList (val list <metadata>, ref pPre <node pointer>,
                      ref pLoc <node pointer>, val target <keyType>)
1 pPre = null
2 pLoc = list.head
3 loop (pLoc not null AND target > pLoc->data.key)
  1 pPre = pLoc
  2 pLoc = pLoc->link
4 end loop
5 if (pLoc null)
  1 found = false                  target > last node
6 else
  1 if (target equal pLoc->data.key)
    1 found = true
  2 else
    1 found = false
  3 end if
7 end if
8 return found
end searchList

Append lists（2024 考過）

把 list1 最後一個節點的 link 改成指向 list2 的第一個節點，count 相加。

Algorithm append (ref list1 <metadata>, val list2 <metadata>)
1 if (list1.count zero)
  1 list1.head = list2.head
2 else
  1 pLoc = list1.head
  2 loop (pLoc->link not null)     find last node of list1
    1 pLoc = pLoc->link
  3 end loop
  4 pLoc->link = list2.head
3 end if
4 list1.count = list1.count + list2.count
5 return
end append

Append 要從 list1 的頭走到最後一個節點，list1 有 n 個節點就走 n 步 → O(n)。如果 head structure 有 rear pointer（指向最後一個節點），可以直接 list1.rear->link = list2.head，不用走。這就是投影片說「有 pointer to the last node，程式更有效率」的例子。

Array of lists

3-6 Complex Linked List Structures（進階結構）

Circularly linked list（環狀鏈結串列）

  • 最後一個節點的 link 指回第一個節點。插入或刪除最後一個節點時，要更新 head structure 的 rear pointer，並讓最後節點指向第一個。
  • 可以從中間開始搜尋。兩個問題：target 在目前節點之前 → 自動繞回開頭繼續找；target 不存在 → 記住起始節點，繞一圈回到它就停。
  • 因為最後一個節點指回第一個，所以只要知道 rear，第一個節點就是 rear->link，頭尾都能一步拿到。
例：rear → 40，40 → 10 → 20 → 30 → 40
插在最前面（新節點變第一個）
pNew->link = rear->link        新節點指向原本的第一個 10
rear->link = pNew              最後一個 40 指向新節點
插在最後面：前兩行一樣，再多一行
rear = pNew                    rear 移到新節點

  • Dummy node 放在串列最前面，不存資料（an empty node），head pointer 永遠指向它。
  • 好處：真正的第一個資料節點前面一定有 dummy，所以 pPre 不會是 null，插入、刪除第一個資料節點的寫法就和中間節點一樣。

Doubly linked list（雙向鏈結串列）

  • 每個節點兩個指標：backward pointer（back）指向 predecessor、forward pointer（fore）指向 successor。
  • Head structure 三個 metadata：count、head pointer、rear pointer（非必要，但讓某些演算法更有效率）。
  • Doubly linked circularly linked list：最後一個的 fore 指向第一個，第一個的 back 指向最後一個。
  • 雙向只是多了往回走的 back 指標，節點在記憶體裡還是不連續，所以搜尋仍然是 sequential search，不能用 binary search；差別是可以從 rear 往回找。

• 兩節點之間：新節點指向前後兩個，前後兩個都指向新節點
• 尾端：新節點 back 指向 predecessor、fore 設 null、rear 指向新節點

總複習

考前一天和考前 10 分鐘看這頁就好：必背清單、公式和六段一定要會寫的程式。

必背 12 點 ★★★

  1. Pseudocode 三種結構：sequence（循序）、selection（選擇）、loop（迴圈）。Sequence does not alter the execution path。
  2. Header：precondition（前置條件）＝參數要先滿足什麼；postcondition（後置條件）＝做完後輸出的狀態；return condition（回傳條件）。
  3. Atomic data type（原子資料型態）：integer、floating point、character。Statement 不是。
  4. ADT：使用者只看得到 operation name and its parameters（操作名稱與參數）。
  5. Big-O：係數設 1，只留最大項。Binary search O(log n)、sequential O(n)、矩陣相加 O(n²)、相乘 O(n³)。
  6. Sentinel search 把迴圈的兩個條件減成一個（Knuth）。Probability search 會在搜尋時把找到的元素往前換。
  7. Binary search 停止：找到，或 first > last。1024 個元素答 10。
  8. Direct hashing：no synonyms, no collisions。Modulo-division：用餘數，任何 list size 都能用，偏好質數。
  9. Open addressing：linear probe、quadratic probe、double hashing（pseudorandom）、key offset。Chaining 不是。
  10. Clustering：linear probe → primary clustering；secondary clustering 沿著 collision path，用 key offset 減少。
  11. searchList 六種結果表：pLoc 停在第一個 ≥ target 的節點；全部都比較小 → pPre = last node、pLoc = null。
  12. insertNode 順序：先 pNew->link，再改 head 或 pPre->link。
