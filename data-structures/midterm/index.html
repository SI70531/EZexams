1-1 Pseudocode（虛擬碼）

什麼是 pseudocode 投影片 3

  • Pseudocode: An English-like representation of the code（像英文的程式寫法）。
  • Part English（一半是英文）＋ part structured code（一半是結構化程式碼）。
  • Structured code 的部分 consists of sequence, selection, and iteration（由循序、選擇、重複三種結構組成）。
投影片框起來的句子One of the most common tools for defining algorithms is pseudocode, which is part English, part structured code.

Basic format for data type 與 structure of the data 投影片 4

宣告一個資料時寫兩樣東西：name of the data（資料名稱）和 type enclosed in pointed brackets（用尖括號 < > 包起來的型態）。

count <integer>                 名稱 count，型態 integer

node                            一個結構（structure of the data）
    data    <dataType>

圖解：node 這個結構有兩個欄位，data 放資料、link 放「指向另一個 node 的指標」。投影片特別註明 assuming that dataType has been previously defined（假設 dataType 之前已經定義過）。這個 node 就是第 3 章 linked list 的節點。

Statement constructs（三種結構） 投影片 13–14 ★★★

Any algorithm could be written with only three programming constructs：sequence、selection、loop。

Sequence（循序）
A series of statements that do not alter the execution path within an algorithm.
一行接一行做下去，不會跳。
Selection（選擇）
Selection statements evaluate one or more alternatives.
1 if (condition)
  1 action1
2 else
  1 action2
3 end if
Loop（迴圈）
Iterates a block of code.
重複執行一段程式，pseudocode 的 loop 和 while 一樣，先測條件再做。
考古題陷阱「A sequence changes the execution path」是錯的；sequence 的定義就是 do not alter the execution path。

Pseudocode example：Algorithm 1-2 投影片 15–16

algorithm deviation
   Pre    nothing
   Post   average and numbers with their deviation printed
1 i = 0
2 loop (not end of file)
  1 read number into array[i]
  2 sum = sum + number
  3 i = i + 1
3 end loop
4 average = sum / i
5 print (average)
6 j = 0
7 loop (j < i)
  1 devFromAve = array[j] - average
  2 print (array[j], devFromAve)
  3 j = j + 1
8 end loop
9 return
end deviation
Algorithm 1-2　Print deviation from mean for series of numbers

這段在做什麼：第一個 loop 把檔案裡的數字一個個讀進 array[i]，同時加總；讀完 i 剛好是讀了幾個數，所以 average = sum / i。第二個 loop 從 j = 0 跑到 j < i，印出每個數和它離平均多遠（deviation）。

Algorithm 1-2 analysis（投影片 16 的三點）：

  1. There are no parameters. 如果有，就要寫出它是 pass by reference（ref）還是 pass by value（val）、名稱和型態。
  2. 這裡用的是 code-oriented pseudocode（偏程式的寫法，i = i + 1），而不是 “tight English” pseudocode（純英文寫法，Add one to i）。
  3. Pseudocode arrays are indexed starting at 0.（所以第二個 loop 從 j = 0 開始、條件是 j < i。）

Atomic data 與 composite data 投影片 19–20 ★★★

  • Atomic data：Data that we choose to consider as a single, nondecomposable entity（我們把它當成一個不能再拆的整體）。
  • Atomic data type 有兩部分：1. A set of values（一組值）、2. A set of operations on values（對這些值的操作）。
Atomic data typevaluesoperations
integer−∞, …, −2, −1, 0, 1, 2, …, ∞*, +, −, %, /, ++, −−, …
floating point−∞, …, 0.0, …, ∞*, +, −, /, …
character\0, …, 'A', 'B', …, 'a', 'b', …, ~<, >, …

圖解：三種 atomic data type 的 operations 不一樣。integer 有 %（取餘數）和 ++、--；floating point 沒有 %；character 只列比較運算 <、>。這就是「data type = values ＋ operations」：同樣是 /，integer 和 floating point 的結果也不同。

Example of an ADT：銀行排隊 投影片 24–25

  • 系統分析師要 simulate the waiting line of a bank，需要模擬一個 queue。

Sequential search algorithm：Algorithm 2-1 投影片 8–10 ★★★

Must tell the calling algorithm two things：Did it find the target data?（有沒有找到）和 At what index are the target data found?（在哪個 index）。所以 requires four parameters：

  1. the list
  2. an index (to the last element)
  3. the target
  4. the address (where the target is found)
algorithm SeqSearch (val list   <array>,
                     val last   <index>,
                     val target <keyType>,
                     ref locn   <index>)
Locate the target in an unordered list of elements.
   Pre    list must contain at least one element
          last is index to last element in the list
          target contains the data to be located
          locn is address of index in calling algorithm
   Post   if found--matching index stored in locn & found true
          if not found--last stored in locn & found false
   Return found <Boolean>
1 looker = 0
2 loop (looker < last AND target not equal list[looker])
  1 looker = looker + 1
3 end loop
4 locn = looker
5 if (target equal list[looker])

6 else
  1 found = false
7 end if

細節：迴圈條件是 looker < last（不是 ≤），所以 looker 最多停在 last，不會跑出 array。迴圈結束後再用第 5 行判斷停下來那格是不是 target：是 → found；不是（停在 last 也不等）→ not found，locn 存 last。

Variations on sequential searches 投影片 11–12

Three useful variations：the sentinel search、the probability search、the ordered list search。

  • Observation：Algorithm 2-1 的 loop 每圈測兩個條件：end of list、target not found。
  • Knuth states：“When the inner loop of a program tests two or more conditions, an attempt should be made to reduce it to just one condition.”

Sentinel search：Algorithm 2-2 投影片 13–15 ★★★

A target is put in the list by adding a sentinel entry at the end of the array and placing the target in the sentinel.（在 array 尾端多加一格「哨兵」，把 target 放進去，保證一定找得到，迴圈就不用再測 end of list。）

Probability search：Algorithm 2-3 投影片 16–19

  • The array is ordered with the most probable search elements at the beginning and the least probable at the end.
  • Especially useful when few elements are the targets for most of the searches.（少數幾個元素被找的次數佔大部分。）
  • To ensure the probability ordering is correct over time：每次找到就和前一個元素交換（exchange the located element with the element before it）。

                             val last   <index>,

element being the target--most probable first, least probable last.
   Pre    list must contain at least one element

Algorithm 2-3　Probability search

細節：4.2 的 if (looker > 0)：已經是第一個就不用換。換完之後 looker = looker − 1，所以回傳的 locn 是元素換過去之後的新位置。

例子：[A, B, C, D, E] 找 D → 找到後 D 和 C 交換 → [A, B, D, C, E]，locn = 2。再找一次 D → 和 B 交換 → [A, D, B, C, E]。常被找的會一格一格往前移。

Ordered list search：Algorithm 2-4 投影片 20–22

  • When searching a small list ordered, sequential search may be more efficient than binary search.（小的有序 list，循序搜尋可能比二元搜尋還快。）
  • Not necessary to search to the end：stop searching when target becomes less than or equal to current element。

Algorithm 2-4　Ordered list search

為什麼先比 list[last]：如果 target < 最後一個，迴圈一定會在 array 裡面停下來（某個元素 ≥ target），所以迴圈只要測一個條件，等於把最後一個元素當成 sentinel。target ≥ 最後一個時直接把 looker 設成 last。找不到時 locn 是「第一個 > target 的元素」，也就是 target 應該插入的位置。

例子：[3, 8, 12, 20, 31] 找 10：10 < 31 → 比 3（10 > 3，繼續）、比 8（10 > 8，繼續）、比 12（10 ≤ 12，停）。12 ≠ 10 → 找不到，locn = 2。只比 3 次，不用比到 31。

Binary search 的觀念 投影片 23–25 ★★★

  • A more efficient algorithm whenever the list starts to become large.
  • Suggest：consider binary searches whenever the list contains more than 16 elements。
  • Idea：testing the data in the element at the middle，判斷 target 在前半還是後半；eliminate half the list until we find the target or the target is not in the list。
  • Three variables are required：the beginning（first）、the middle（mid）、the end（last）of the list。
  • Two conditions terminate binary search：the target is found、first becomes larger than last。
  • mid = (first + last) / 2（整數除法，小數捨去）。
  • 前提：list 必須已排序，而且是 array（要能直接跳到中間）。

2-2 Hashed List Searches（雜湊搜尋）

Hashed search 的目標 投影片 44–45 ★★★

  • The goal of a hashed search：to find the data with only one test（只比一次就找到）。
  • The key determines the location of the data：用 hashing algorithm 把 key 轉成 index。
  • 另一種說法：A key-to-address transformation in which the keys map to addresses in a list.

Synonyms、collision、home address、prime area 投影片 46–48 ★★★

When two keys collide at a home address, resolve the collision by placing the later data in another location.（後來的放到別的地方。）

圖解 Figure 2-7 依序插入 A、B、C：
1. hash(A) = 8，8 是空的 → A 放在 [8]。
2. hash(B) = 8，B and A collide at 8 → collision resolution 把 B 移到 [16]。

Locate an element 與 probe 投影片 49

  • 找資料時 use the same algorithm that we used to insert it：先 hash key、看 home address；if it doesn’t contain the desired element, use the collision resolution algorithm to determine the next location。
  • Probe：Each calculation of an address and test for success（算一次地址並檢查一次 = 一次 probe）。

Hashing methods 投影片 50

圖解 Figure 2-8八種基本方法：Direct、Subtraction、Modulo division、Digit extraction、Midsquare、Folding、Rotation、Pseudorandom generation。下面照投影片順序一個一個講。最下面的互動計算機可以輸入任何 key，八種方法一次算給你看。

Direct method 投影片 51–54

  • The key is the address without any algorithmic manipulation.
  • Data structure must contain an element for every possible key.（每個可能的 key 都要有一格。）
  • Evaluation：the situations you can use direct method is limited, but it is very powerful，因為 it guarantees no synonyms and no collisions。
  • Application：用 day of the month 當 key，把銷售額加到對應的累加器：
dailySales[sale.day] = dailySales[sale.day]
                     + sale.amount;

More complex example：公司員工少於 100 人，員工編號 1～100，the employee number can be directly used as the address of any individual record。

圖解 Figure 2-9key 005 → address 5、key 100 → address 100、key 002 → address 2，key 和 address 完全一樣。[000] 是灰色的 (not used)：因為員工編號從 1 開始，0 號格子永遠不會用到。

Subtraction method 投影片 55

  • 用在 keys are consecutive but do not start from 1。例：員工編號 1001～1100（100 個人），subtracts 1000 from the key to determine address（1001 → 1、1100 → 100）。
  • Only be used for small lists in which the keys map to a densely filled list.（key 要很密集，才不會浪費空間。）
  • Direct 和 subtraction 一樣保證不碰撞。

Modulo-division method 投影片 56–58 ★★★

  • Also known as division remainder：divides the key by the array size and uses the remainder for the address。
  • address = key MODULUS listSize
  • This algorithm works with any list size，但 prime number is better for the list size：produce fewer collisions than other list size。
  • Application：新的員工編號系統能處理 1,000,000 人，但只準備 300 筆空間；the first prime number greater than 300 is 307。Brian Devaux 的員工編號 121267：
121267 / 307 = 395 with remainder of 2
Therefore: hash(121267) = 2

Folding method 投影片 62–64 ★★★

  • 兩種：fold shift 和 fold boundary。
  • Fold shift：the key value is divided into parts whose size matches the size of the required address（切成和地址一樣長的幾段），the left and right parts are shifted and added with the middle part（左右兩段直接移過來和中間相加）。
  • Fold boundary：the left and right numbers are folded on the boundary between them and the center number（左右兩段沿著和中間的邊界「摺」過來，所以數字順序會反過來）。
  • The two folding methods give different hashed addresses.
圖解 Figure 2-11 key 123456789，要 3 位數地址，所以切成 123 | 456 | 789。
(a) Fold shift：123 + 456 + 789 = 1368，超過 3 位，最前面的 1 Discarded（丟掉）→ 368。
(b) Fold boundary：左右兩段 Digits reversed：123 → 321、789 → 987；321 + 456 + 987 = 1764 → 丟掉 1 → 764。
同一個 key，兩種摺法得到不同地址（368 vs 764）。
考試必算：fold boundary（每兩位一組）＋ modulo division key 224562，list size 19：切成 22 | 45 | 62 → 左右反轉 22→22、62→26 → 22 + 45 + 26 = 93 → 93 MOD 19 = 17（home address）。
如果是 fold shift 就不反轉：22 + 45 + 62 = 129 → 129 MOD 19 = 15。
注意考古題是「摺完相加後再 MOD listSize」，不是丟掉進位；照題目寫的做。

Rotation method 投影片 65–67

  • Usually works with other hashing methods，most useful when keys are serial（連號）。
  • 例：If hashing keys are identical except the last character（只有最後一位不同）→ rotating the last character to the front of the key。
圖解 Figure 2-12 600101～600105 只有最後一位不同（藍色那位）。把最後一位轉到最前面：160010、260010、360010、460010、560010。
投影片 67 的分析：轉完之後 all keys now end in 60010，如果直接用 modulo division 效果不好；rotation 通常和 folding / pseudorandom 一起用。例如 fold shift 成兩位數地址：16 + 00 + 10 = 26，其他依序是 36、46、56、66，spreading the data more evenly（分得比較開）。

  • 再用 modulo division 把亂數縮到地址範圍內：the result is divided by the list size, with the remainder being the hashed address。
  • 常見的 RNG：y = ax + c。For maximum efficiency, the factors a and c should be prime numbers.

2-3 Collision Resolution（碰撞處理）

為什麼需要 collision resolution 投影片 76–77

  • No hashing methods are 1-to-1 mapping，except the direct and subtraction methods。所以一定會碰撞。
  • Several collision resolution methods; they are independent of the hashing algorithm（和用哪種 hashing method 無關，可以任意搭配）。
圖解 Figure 2-13三大類：Open addressing（在 prime area 裡找空位，底下四種：Linear probe、Quadratic probe、Pseudorandom、Key offset）、Linked lists（碰撞的串到 overflow area）、Buckets（一個地址放好幾筆）。

三個概念之一：Load factor 投影片 78 ★★★

α = (k / n) × 100，k: the number of filled elements（已填的格數）、n: the total number of elements（總格數）。例：19 格放了 9 個 → 9/19 × 100 ≈ 47%。load factor 越高，越容易碰撞。

三個概念之二：Clustering 投影片 79–80 ★★★

  • Clustering：the tendency of data to build up unevenly across a hashed list（資料不平均地堆在某些地方）。
  • clustering 嚴重時：the number of probes to locate an element grows，reduces the processing efficiency of the list。
  • Primary clustering：occurs when data cluster around a home address，easy to identify（一眼看得出某一區塞滿）。
  • Secondary clustering：occurs when data become grouped along a collision path throughout a list，not easy to identify（資料散在整張表，但都在同一條碰撞路徑上）。
  • Goal：design hashing algorithm to minimize clustering。

三個概念之三：檢查的元素數量要有上限 投影片 81

  • Number of elements examined for a place to store the data must be limited.
  • 傳統做法「檢查到所有元素都看過」有問題：the search is not sequential（走到「最後一格」不代表每格都檢查過）；examining every element would be time-consuming；而且 some of the collision resolution techniques cannot physically examine all of the elements（例如 quadratic probe 根本走不到某些格子，見 Table 2-2）。

  • 缺點：tend to produce primary clustering。

Linked list resolution 投影片 92–94

  • A major disadvantage to open addressing：each collision resolution increases the probability of future collision（Figure 2-7 的 C 就是這樣被連累）。
  • Linked list：an ordered collection of data, each element contains the location of next element。
  • Uses two storage areas：the prime area 和 the overflow area。
  • Linked list data can be stored in any order，最常用：a last in-first out (LIFO) sequence（element is placed at the beginning of the overflow list，新的插在 overflow list 最前面）或 a key sequence（依 key 排序）。
  • 這個方法又叫 chaining。它不屬於 open addressing，因為碰撞的資料放到 prime area 外面了。考古題選項「linear probe, quadratic probe, double hashing, and chaining」就是錯在 chaining。

Bucket hashing 投影片 95–96

  • Because a bucket can hold multiple data, collisions are postponed until the bucket is full.
  • 兩個問題：it uses significantly more space（每個地址要預留好幾格）；it does not completely resolve the collision problem（bucket 滿了還是要用別的方法）。
圖解 Figure 2-17 每個 bucket 能放 3 筆。Bucket 1 已經放了 070918、166702、367173 三個 home 1 的 key，滿了。第 4 個 home 1 的 key 572556 Chris Walljasper 進來時 bucket 1 沒位置，用 linear probe 放到下一個 bucket 2（Linear probe places here）。所以 bucket 只是延後碰撞，沒有消除碰撞。

Combination approaches 投影片 97

A complex implementation often uses multiple steps. 例：一個大型資料庫先 hash 到 bucket；if the bucket is full, it uses a set number of linear probes, then uses a linked list overflow area（先做固定次數的 linear probe，還是不行再放 linked list overflow area）。

3-1 Linear List Concepts（線性串列）

Preface：array vs. linked list 投影片 3

Arrays
Arrays are easy to create and use，but they are inefficient when sequenced data need to be inserted or deleted（插入刪除要搬一堆資料）。
Linked list
Linked list efficiently handles insertion and deletion，it is inefficient for search and retrieval（只能從頭一個一個找）。

Linear list 投影片 4

The simplest linear list structure, the array, is found in virtually all programming. 線性串列的特色是每個元素有唯一的 successor（下一個）。

Linear list can be divided into two categories：General 和 Restricted。

General list 與 restricted list 投影片 5–7 ★★★

3-2 Linked List Concepts（鏈結串列觀念）

Linked list 投影片 16–17 ★★★

  • An ordered collection of data；each element contains the location of next element。
  • Each element contains two parts：data（holds the useful information）和 link（used to chain the data together）。
  • Singly linked list：it contains only one link to a single successor。
  • Advantage and limit：easily inserted and deleted；cannot use a binary search（不能直接跳到中間）。
  • Empty linked list：a null head pointer。
圖解 Figure 3-6 紅色方塊都是指標。(a) pHead 指向第一個節點；每個節點左邊白色是 data、右邊紅色是 link，link 指向下一個節點；最後一個節點的 link 打叉 = null（後面沒有了）。
(b) 空串列：pHead 本身就是 null（打叉），一個節點都沒有。判斷串列空不空，看的就是 head 是不是 null（或 count 是不是 0）。

Node 投影片 18–19

  • Elements in a linked list are called nodes.
  • A node has at least two fields：一個放 data，另一個是 the address of the next node in the sequence。
  • Self-referential structures：nodes in a linked list are called self-referential structures，因為 each instance of the structure contains a pointer to another instance of the same structural type（node 裡面有一個指向 node 的指標）。

Linked list data structure 投影片 20–23 ★★★

  • Head node structure：a structure that stores the head pointer and metadata；metadata = data about the list（例如 count）。

Insert node：三個步驟 投影片 26 ★★★

Insert node adds data to a linked list. Three steps to the insertion：

  1. Allocate memory for the new node and insert data.
  2. Point the new node to its successor.
  3. Point the new node’s predecessor to the new node.

Two states of the node that precedes the new node：the predecessor is null or not null。四種插入情況（empty、beginning、middle、end）最後只剩這兩種寫法。

Insert into empty list 投影片 27–28

Set the link of the new node to a null pointer，assign the list head pointer the address of new node。

pNew->link = list.head        Set link to null pointer
list.head  = pNew             Point list to first node

Note the order of these two statements：must first point the new node to its successor, then change the head pointer。（空串列時 list.head 是 null，所以第一行等於把 pNew->link 設 null。）

圖解 Figure 3-10(a) count 0、head null；pNew 指向剛配置好的 75（它的 link 還沒設定）。(b) 執行兩行之後：75 的 link 拿到 head 原本的 null（打叉），head 改指 75，count 變 1。

Insert at beginning 投影片 29–30

Insert a node before the first node of the list：point the new node to the first node of the list，set the head pointer to point to the new first node。

pNew->link = list.head
list.head  = pNew

Logically, inserting into an empty list is the same as inserting at the beginning of a list.（兩行程式一模一樣。）

圖解 Figure 3-11(a) list 裡只有 75，pNew 指向新的 39。(b) 第一行：39 的 link = head 原本指的 75；第二行：head 改指 39。count 1 → 2。如果順序反過來，先改 head，75 的位址就沒人記得了。

Insert in middle 投影片 31–32

To insert a node between two nodes, we point the new node to its successor, then point its predecessor to the new node. The address of the new node’s successor can be found in the predecessor’s link field.

pNew->link = pPre->link
pPre->link = pNew

Delete node：步驟與情況 投影片 37–38

  • Logically removes a node from the linked list by changing various link pointers.

Ch1 Introduction（導論）

1-1

Pseudocode（虛擬碼）

口訣
  • 三種結構：「循、選、迴」＝sequence、selection、loop
  • Pseudocode 三種結構：sequence（循序）、selection（選擇）、loop（迴圈）。Sequence does not alter the execution path。
  • Header：precondition（前置條件）＝參數要先滿足什麼；postcondition（後置條件）＝做完後輸出的狀態；return condition（回傳條件）。沒有前置條件也要寫 Pre nothing。
  • val＝pass by value；ref＝pass by reference，用來把結果寫回（output parameter 可以很多個，return value 只有一個）。
  • Statement numbers：3.1 是第 3 行底下展開的第 1 行。
1-2

The Abstract Data Type（抽象資料型態）

  • Atomic data type（原子資料型態）：integer、floating point、character。Statement 不是。
  • Data type＝a set of data ＋ the operations on the data；composite 可拆成有意義的部分（電話號碼）；data structure＝atomic／composite 依定義好的關係組成（array、record）。
  • ADT：使用者只在乎 what it can do，不在乎 how；隱藏實作＝abstraction。底層是 array 還是 linked list，使用者不該知道。
  • Encapsulation：一個 object 的處理全部包在 library 裡、對使用者隱藏。銀行排隊例：寫一個通用的 queue ADT，分析師才能專心在應用。
1-3

A Model for an ADT（ADT 模型）

  • ADT：使用者只看得到 operation name and its parameters（操作名稱與參數）。
  • 模型裡兩樣東西：data structure 和 operational functions，都不在 user's scope。
  • 使用者拿到的是 pointer to a hidden structure；class template 用 TYPE（資料）和 KTYPE（key，optional）。
1-4

Algorithm Efficiency（演算法效率） ★★★

口訣
  • 加減 → linear；乘除 → logarithmic；內層看外層變數 → dependent，要加總
  • Big-O：係數設 1，只留最大項。Binary search O(log n)、sequential O(n)、矩陣相加 O(n²)、相乘 O(n³)。
  • i += 2 → n/2 → O(n)；i *= 2 或 i /= 2 → log₂n → O(log n)；外層 n × 內層 log₂n → O(n log n)；j ≤ i → n(n+1)/2 → O(n²)。
  • 數乘除迴圈：i = 1, 2, 4 … 找最大的 2ᵏ 還滿足條件，次數 = k + 1。i < 1000 → 512 是最後一個 → 10 次。

Ch2 Searching（搜尋）

2-1

List Searches（串列搜尋）

  • Sequential search：沒排序、小、不常搜尋的 list 用；四個參數 list、last、target、ref locn；O(n)。
  • Sentinel search 把迴圈的兩個條件減成一個（Knuth）。Probability search 會在搜尋時把找到的元素往前換。
  • Ordered list search：target ≤ 目前元素就停，不用找到底。
  • Binary search 停止：找到，或 first > last。1024 個元素答 10。
2-2

Hashed List Searches（雜湊搜尋）

  • 目標：只比一次就找到；hashing＝key-to-address transformation。
  • 名詞：synonyms（hash 到同一位置的 keys）、collision（位置被佔）、home address、prime area、probe（每算一次地址並測試）。
  • Direct hashing：no synonyms, no collisions。Modulo-division：用餘數，任何 list size 都能用，偏好質數。
  • 其他：subtraction、digit extraction（取第幾位）、midsquare（平方取中）、fold shift／boundary、rotation（最後一位轉到最前）、pseudorandom（y = ax + c 再 MOD）。
Fold shift 22|45|62 → 22 + 45 + 62 = 129 Fold boundary 22|45|62 → 22 + 45 + 26 = 93 (左右兩段反轉) Home address sum MOD listSize 93 MOD 19 = 17
2-3

Collision Resolution（碰撞處理）

  • Open addressing：linear probe、quadratic probe、double hashing（pseudorandom）、key offset。Chaining 不是。
  • Clustering：linear probe → primary clustering；secondary clustering 沿著 collision path，用 key offset 減少。
  • Bucket hashing 的問題：more space；does not completely resolve collisions。
  • Linked list resolution：prime area + overflow area（LIFO 或 key sequence）。
Linear probe next = (addr + 1) MOD size Quadratic next = (addr + i²) MOD size i = 1, 2, 3 … Key offset offset = sum / size (取商) next = (offset + addr) MOD size Load factor k / n × 100 9 / 19 ≈ 47%

Ch3 Linked Lists（鏈結串列）

3-1

Linear List Concepts（線性串列）

  • Array 好建好用但插入刪除要搬資料；linked list 插入刪除快但 search、retrieval 沒效率。
  • General list：random 或 ordered。Restricted list FIFO / LIFO → queue / stack。
  • 四種操作：insertion、deletion、retrieval、traversal。Not applicable to restricted lists → traversal。
3-2

Linked List Concepts（鏈結串列觀念）

  • 每個 node 至少 data ＋ link；self-referential structure。
  • 節點在記憶體不連續（no physical relationship）→ 不能用 binary search。Empty list：head 是 null。
  • head structure 放 metadata（count、pos、head）；pLoc＝目前節點、pPre＝前一個。
  • Not always necessary but improves efficiency → rear pointer。
3-3

Linked List Algorithms（十個基本演算法） ★★★

  • insertNode 順序：先 pNew->link，再改 head 或 pPre->link（先接後面再改前面，不然會弄丟後面的節點）。
  • insert 四情況（empty、beginning、middle、end）→ 兩種邏輯：pPre 是 null／不是 null；overflow 回傳 false。
  • delete 四情況 → 兩種：刪第一個、刪其他；pLoc 呼叫前就要先找到。
  • searchList 六種結果表：pLoc 停在第一個 ≥ target 的節點；全部都比較小 → pPre = last node、pLoc = null。
  • How to test full list → allocate memory and see if it succeeds。

insertNode

if (pPre null) pNew->link = list.head list.head = pNew else pNew->link = pPre->link pPre->link = pNew list.count = list.count + 1

deleteNode

dataOut = pLoc->data if (pPre null) list.head = pLoc->link else pPre->link = pLoc->link list.count = list.count - 1 recycle (pLoc)

searchList

pPre = null pLoc = list.head loop (pLoc not null AND target > pLoc->data.key) pPre = pLoc pLoc = pLoc->link found = (pLoc not null AND target equal pLoc->data.key)

destroyList

loop (list.count not zero) dltPtr = list.head list.head = dltPtr->link list.count = list.count - 1 recycle (dltPtr) list.pos = null
3-4

Processing a Linked List（整合程式）

  • addNode：searchList 找插入點 → insertNode；要決定 duplicate 和 overflow 怎麼處理。
  • Remove a node → searchList → deleteNode；找不到回傳 false。
  • printList：先測 empty；第一次 getNext 的 fromWhere 是 0。
  • 測試 insert／delete 各 4 種：null list、第一個、中間、最後。
3-5

List Applications（應用）

  • append：list1 最後一個節點的 link 指向 list2 的第一個，count 相加；要走到底 → O(n)，有 rear pointer 就直接 list1.rear->link = list2.head。
  • Array of lists：array 存多個 head，可表示 2D array（每條 list 是一列）。

append

if (list1.count zero) list1.head = list2.head else pLoc = list1.head loop (pLoc->link not null) pLoc = pLoc->link pLoc->link = list2.head list1.count = list1.count + list2.count
3-6

Complex Linked List Structures（進階結構）

  • Circular list：最後一個指回第一個；知道 rear，第一個就是 rear->link。插在最前：pNew->link = rear->link；rear->link = pNew（插在最後再加 rear = pNew）。
  • Circular list, target not found → save the starting node, stop when circled back。
  • Dummy node：不存資料、head 永遠指向它 → pPre 不會是 null，刪插第一個資料節點和中間一樣。2025 第 28 題：最後一個指回 dummy → 有 dummy 的環狀串列。
  • Doubly linked：back、fore 兩個指標；insertDbl returns 0 / 1 / 2 → overflow / success / duplicate。
  • Multilinked presidents list → two links: president and spouse。

if (pDlt->back not null) pDlt->back->fore = pDlt->fore else list.head = pDlt->fore if (pDlt->fore not null) pDlt->fore->back = pDlt->back else list.rear = pDlt->back recycle (pDlt)
