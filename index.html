跨裝置同步

sync/
只存在這台裝置

所有科目的作答、分數和選擇題進度，會存到你 GitHub 帳號裡一個私人的 Gist。每台裝置只要貼一次同一把金鑰，打開哪一科都是同樣的進度。

  1. 打開 GitHub 建立金鑰頁（已經幫你勾好 gist）。
  2. Expiration 選 No expiration 或期末之後的日期，拉到最下面按 Generate token。
  3. 複製那串 ghp_ 開頭的金鑰，貼到下面按「連結」。其他裝置也貼同一串。

金鑰只存在這台裝置的瀏覽器裡，而且只有建立和修改 Gist 的權限，看不到你的程式碼。

進度會自動同步：作答後 2 秒內上傳，切回分頁或打開頁面時下載最新的。

作答和分數只存在你這台裝置的瀏覽器裡
