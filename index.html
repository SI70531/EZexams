grading/
Keyword grading

Written questions are currently scored by keyword matching, which only checks whether key terms appear. With a free Google key, written questions in statistics, operating systems and data structures are graded by AI, with a score and a Chinese comment. No credit card needed.

  1. Sign in with a Google account and open Google's free key page (AI Studio).
  2. Press Create API key (the first time you'll accept the terms and pick a project; the default is fine).
  3. Press Copy key, paste the whole key below, and press Activate. Paste it once on each device.

The key is stored only in this device's browser and is never uploaded. The free quota is roughly 10 requests per minute and thousands per day; one “Grade all” counts as 1 request. Note: on the free tier Google may use the content you submit to improve its models, so don't put personal information in your answers.
