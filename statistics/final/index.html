5.1 Random Variables隨機變數

  • A random variable is a numerical description of the outcome of an experiment.隨機變數是實驗結果的數值描述。
  • Discrete random variable: takes a finite number of values, or an infinite sequence of values (0, 1, 2, …). You can count it.離散隨機變數：值的個數有限，或是無限但可一個個數（0, 1, 2, …）。可以「數」出來。
  • Continuous random variable: can take any value in an interval (or a collection of intervals). You measure it.連續隨機變數：可以是某個區間內的任何值。要用「量」的。
  • Test: picture the possible values as points on a line. If every point between two possible values is also possible, the variable is continuous.判斷法：把可能的值畫成數線上的點；如果任兩個可能值之間的每一點也都可能，就是連續。

5.2 Developing Discrete Probability Distributions建立離散機率分配

  • The probability distribution of a random variable describes how probabilities are distributed over its values. For a discrete variable it is given by a probability function f(x), as a table, a graph or a formula.機率分配描述機率如何分布在隨機變數的各個值上。離散變數用機率函數 f(x) 表示，可以是表格、圖或公式。

5.3 Expected Value and Variance期望值與變異數

  • Expected value (mean) E(x) = μ = Σx f(x): a weighted average of the values, with the probabilities as weights. It is a measure of central location.期望值（平均數）E(x) = μ = Σx f(x)：以機率為權數的加權平均，是集中趨勢的量數。
  • E(x) does not have to be a possible value: a game paying $0 or $2 with equal chance has E(x) = $1. In one play you never get $1; over many plays the average payoff approaches $1.E(x) 不一定是可能出現的值：各半機率拿 $0 或 $2，E(x) = $1。玩一次永遠拿不到 $1，玩很多次平均會趨近 $1。
  • Variance Var(x) = σ² = Σ(x − μ)² f(x): a weighted average of the squared deviations. Standard deviation σ = √σ², in the same units as x.變異數 Var(x) = σ² = Σ(x − μ)² f(x)：離差平方的加權平均。標準差 σ = √σ²，單位和 x 相同。

5.5 Binomial Probability Distribution二項機率分配

The probability of a given number of successes in a fixed number of independent trials. Four properties of a binomial experiment:在固定次數的獨立試驗中，得到某個成功次數的機率。二項實驗的四個性質：

  1. A sequence of n identical trials.n 次相同的試驗。
  2. Two outcomes on each trial: success and failure.每次只有兩種結果：成功、失敗。
  3. The probability of success p does not change from trial to trial (the stationarity assumption).成功機率 p 每次都不變（穩定性假設）。
  4. The trials are independent.試驗之間互相獨立。

Properties 2 to 4 describe one Bernoulli trial; repeating it n times gives the binomial experiment. x = the number of successes in the n trials.性質 2 到 4 描述的是一次伯努利試驗；重複 n 次就是二項實驗。x = n 次中成功的次數。

Binomial probability functionf(x) = C(n, x) px (1 − p)n − x = n! / [x!(n − x)!] · px(1 − p)n − x
E(x) = μ = np　　Var(x) = σ² = np(1 − p)　　σ = √[np(1 − p)]C(n, x) 是「n 次中哪 x 次成功」的排法數；px(1 − p)n − x 是其中一種排法的機率。

Evans Electronics: each hourly employee leaves within the year with p = 0.10. Choose n = 3 employees; what is P(exactly 1 leaves)? Each path of the tree with one S and two F has probability (0.1)(0.9)² = 0.081, and there are C(3, 1) = 3 such paths.Evans 電子：每位時薪員工一年內離職機率 p = 0.10。隨機挑 n = 3 人，恰 1 人離職的機率？樹狀圖上一條「1 個 S、2 個 F」的路徑機率是 (0.1)(0.9)² = 0.081，這樣的路徑有 C(3, 1) = 3 條。

f(1) = 3!/(1!2!) × (0.1)¹(0.9)² = 3 × 0.081 = 0.243. The whole distribution: f(0) = .729, f(1) = .243, f(2) = .027, f(3) = .001. E(x) = 3(0.1) = 0.3 employees, Var(x) = 3(0.1)(0.9) = 0.27, σ = 0.52.f(1) = 3 × 0.081 = 0.243。整個分配：f(0) = .729、f(1) = .243、f(2) = .027、f(3) = .001。E(x) = 0.3 人、Var(x) = 0.27、σ = 0.52。

  • Binomial tables list f(x) for given n and p (row n = 3, x = 1, column p = .10 → .2430). With calculators and software the tables are rarely needed. Cumulative probabilities add f(x): P(x ≤ 1) = .729 + .243 = .972.二項機率表直接查 f(x)（n = 3、x = 1、p = .10 那格是 .2430）。累積機率就是把 f(x) 加起來：P(x ≤ 1) = .972。
  • Why E(x) = np: one trial gives 1 with probability p and 0 with 1 − p, so its mean is 1·p + 0·(1 − p) = p; n independent trials add to np.為什麼 E(x) = np：一次試驗成功記 1、失敗記 0，期望值 = 1·p + 0·(1 − p) = p；做 n 次加起來就是 np。

5.6 Poisson Probability Distribution卜瓦松機率分配

  • The number of occurrences in a specified interval of time or space: arrivals at a car wash in one hour, repairs needed on 10 km of highway, leaks in 100 km of pipeline. x = 0, 1, 2, … with no upper limit.某段時間或空間區間內發生的次數：一小時內到洗車場的車數、10 公里公路需要修補的地方、100 公里管線的漏洞數。x = 0, 1, 2, …，沒有上限。
  • Two properties of a Poisson experiment: (1) the probability of an occurrence is the same for any two intervals of equal length; (2) occurrence in one interval is independent of occurrence in any other interval.卜瓦松實驗兩個性質：(1) 等長的區間發生機率相同；(2) 不同區間是否發生彼此獨立。
Poisson probability functionf(x) = μx e−μ / x!　　μ = mean number of occurrences in the interval, e = 2.71828
Mean = variance = μμ 是「這個區間」的平均次數；卜瓦松分配的平均數和變異數相等。

Mercy Hospital: patients arrive at the emergency room at 6 per hour on weekend evenings. P(4 arrivals in 30 minutes)? First rescale μ to the interval asked: μ = 6/hour = 3 per half-hour. f(4) = 3⁴ e−3 / 4! = 81(0.0498)/24 = 0.1680. Variance for 30-minute periods = μ = 3.Mercy 醫院：週末晚上急診平均每小時 6 位病人。30 分鐘內恰好 4 位的機率？先把 μ 換成題目問的區間：μ = 每小時 6 = 每半小時 3。f(4) = 81(0.0498)/24 = 0.1680。30 分鐘的變異數 = μ = 3。

f(x) never becomes exactly 0, but for large x it is so small that larger values can be ignored.f(x) 不會真的等於 0，但 x 很大時小到可以忽略。

5.7 Hypergeometric Probability Distribution超幾何機率分配

  • Closely related to the binomial, but sampling is without replacement from a finite population, so the trials are not independent and the probability of success changes from trial to trial.和二項很像，但是從有限母體抽出不放回，所以試驗不獨立，成功機率每次都會改變。
Hypergeometric probability functionf(x) = C(r, x) · C(N − r, n − x) / C(N, n),　for 0 ≤ x ≤ r and 0 ≤ n − x ≤ N − r (otherwise f(x) = 0)
N = population size, r = successes in the population, n = number of trials (sample size), x = successes in the sample
E(x) = n(r/N)　　Var(x) = n(r/N)(1 − r/N)[(N − n)/(N − 1)]分子：從 r 個成功裡選 x 個 × 從 N − r 個失敗裡選 n − x 個；分母：從 N 個裡選 n 個的所有方法。

Neveready's batteries: 2 dead batteries got mixed with 2 good ones (N = 4, r = 2 good). Bob picks n = 2. P(both good) = C(2, 2)C(2, 0)/C(4, 2) = 1 × 1 / 6 = 0.1667. E(x) = 2(2/4) = 1; Var(x) = 2(0.5)(0.5)(2/3) = 0.333.Neveready 電池：2 顆沒電的和 2 顆好的混在一起（N = 4、r = 2 顆好的），Bob 拿 n = 2 顆。兩顆都好的機率 = 1/6 = 0.1667。E(x) = 1；Var(x) = 0.333。

  • Let p = r/N. Then E(x) = np exactly like the binomial, and Var(x) = np(1 − p) times the factor (N − n)/(N − 1). When the population is large, that factor is close to 1, so the hypergeometric can be approximated by a binomial with n trials and p = r/N.令 p = r/N，E(x) = np 和二項一樣；Var(x) 是 np(1 − p) 再乘上 (N − n)/(N − 1)。母體很大時這個因子接近 1，所以可以用二項分配近似（n 次、p = r/N）。

Chapter summarySummary 本章總結
  • A random variable gives a number to each outcome; discrete = countable values, continuous = any value in an interval.隨機變數把每個結果變成數字；離散＝可數的值，連續＝區間內任何值。
  • A discrete probability function needs f(x) ≥ 0 and Σf(x) = 1. Discrete uniform: f(x) = 1/n.離散機率函數要 f(x) ≥ 0 且 Σf(x) = 1。離散均勻：f(x) = 1/n。
  • E(x) = Σx f(x); Var(x) = Σ(x − μ)² f(x); σ = √Var(x). JSL: E = 1.2, σ² = 1.66, σ = 1.2884.E(x) = Σx f(x)；Var(x) = Σ(x − μ)² f(x)；σ = √Var(x)。JSL：E = 1.2、σ² = 1.66、σ = 1.2884。
  • Bivariate: σxy = [Var(x + y) − Var(x) − Var(y)]/2 and ρ = σxy/(σxσy). DiCarlo: 0.1350 and 0.1295 (weak positive).二元：σxy = [Var(x + y) − Var(x) − Var(y)]/2，ρ = σxy/(σxσy)。DiCarlo：0.1350、0.1295（弱正相關）。
  • Binomial: n identical independent trials, two outcomes, constant p. f(x) = C(n, x)px(1 − p)n − x, E = np, Var = np(1 − p).二項：n 次相同獨立試驗、兩種結果、p 不變。E = np、Var = np(1 − p)。
  • Poisson: occurrences in an interval. f(x) = μxe−μ/x!, mean = variance = μ. Rescale μ to the interval first.卜瓦松：區間內發生次數。平均數＝變異數＝μ。先把 μ 換成題目的區間。
  • Hypergeometric: sampling without replacement. f(x) = C(r, x)C(N − r, n − x)/C(N, n), E = n(r/N), Var = n(r/N)(1 − r/N)(N − n)/(N − 1).超幾何：抽出不放回。E = n(r/N)、Var 多乘 (N − n)/(N − 1)。
Common trap易錯點
  • Poisson: rescale μ to the interval in the question (6 per hour → 3 per 30 minutes) before using the formula.卜瓦松：先把 μ 換成題目問的區間（每小時 6 → 每 30 分鐘 3），再代公式。
  • Binomial: do not forget the C(n, x) factor. (0.1)(0.9)² = 0.081 is one path; f(1) = 3 × 0.081 = 0.243.二項：別忘了 C(n, x)。(0.1)(0.9)² = 0.081 只是一條路徑；f(1) = 3 × 0.081 = 0.243。
  • "At least one" = 1 − P(x = 0); "more than 2" = P(x ≥ 3), not P(x ≥ 2).「至少一個」＝ 1 − P(x = 0)；「多於 2」＝ P(x ≥ 3)，不是 P(x ≥ 2)。
  • Without replacement from a small population → hypergeometric, not binomial. Its variance has the extra factor (N − n)/(N − 1).從小母體抽出不放回 → 超幾何，不是二項。變異數多一個 (N − n)/(N − 1)。
  • Variance is in squared units; report σ in the units of x. E(x) need not be a possible value of x.變異數是平方單位，σ 才和 x 同單位。E(x) 不一定是 x 能出現的值。
  • Correlation, not covariance, tells the strength: DiCarlo's σxy = 0.135 looks small but only ρ = 0.1295 says "weak".看強弱要用相關係數，不是共變異數：DiCarlo 的 ρ = 0.1295 才說明是「弱」相關。

Continuous Probability Distributions連續機率分配

  • A continuous random variable can take any value in an interval. It makes no sense to ask for the probability of one particular value: P(x = a) = 0.連續隨機變數可以是區間內任何值，問「剛好等於某個值」的機率沒有意義：P(x = a) = 0。
  • Instead we ask for the probability of a value in an interval: P(x₁ ≤ x ≤ x₂) = the area under the graph of the probability density function f(x) between x₁ and x₂.改問落在某個區間的機率：P(x₁ ≤ x ≤ x₂) = x₁ 到 x₂ 之間機率密度函數 f(x) 曲線下的面積。
  • Consequences: the total area under f(x) is 1, and P(x ≤ a) = P(x < a) (the endpoint adds no area).因此：f(x) 底下總面積 = 1；P(x ≤ a) = P(x < a)（端點沒有面積）。
  • f(x) is a height, not a probability; only areas are probabilities.f(x) 是高度，不是機率；只有面積才是機率。

6.1 Uniform Probability Distribution均勻機率分配

  • A random variable is uniformly distributed when the probability is proportional to the interval's length.機率和區間長度成正比時，就是均勻分配。
Uniform densityf(x) = 1/(b − a) for a ≤ x ≤ b, and 0 elsewhere　(a = smallest value, b = largest value)

6.2 Normal Probability Distribution常態機率分配

  • The most important distribution for a continuous random variable and the basis of statistical inference. Examples: heights of people, measurement errors, test scores.描述連續隨機變數最重要的分配，也是統計推論的基礎。例：身高、測量誤差、考試成績。
  • Density: f(x) = [1/(σ√(2π))] e−(x − μ)²/(2σ²), with μ = mean, σ = standard deviation, π = 3.14159, e = 2.71828.密度函數如左，μ = 平均數、σ = 標準差。

Characteristics特性

  • The whole family is defined by μ and σ.整個家族由 μ 和 σ 決定。
  • The highest point is at the mean, which is also the median and the mode; the curve is symmetric (skewness 0) and its tails extend to infinity without touching the axis.最高點在平均數，平均數＝中位數＝眾數；曲線左右對稱（偏態 0），兩尾無限延伸、不碰到橫軸。
  • μ can be any number (negative, zero or positive): it moves the curve left or right.μ 可以是任何數（負、零、正）：決定曲線的左右位置。
  • σ sets the width: a larger σ gives a wider, flatter curve.σ 決定寬度：σ 越大，曲線越寬越扁。
  • Total area = 1, with 0.5 to the left of the mean and 0.5 to the right. If μ = 70, P(x > 70) = 0.5.總面積 = 1，平均數左右各 0.5。μ = 70 時 P(x > 70) = 0.5。

Empirical rule for a normal random variable:經驗法則：

  • 68.26% of the values are within ±1σ of the mean, 95.44% within ±2σ, 99.72% within ±3σ.約 68.26% 落在 μ ± 1σ，95.44% 在 μ ± 2σ，99.72% 在 μ ± 3σ。

Standard Normal Distribution and z標準常態分配與 z

  • A normal random variable with mean 0 and standard deviation 1 has the standard normal distribution; it is written z.平均數 0、標準差 1 的常態變數服從標準常態分配，用 z 表示。
  • Convert any normal x: z = (x − μ)/σ, the number of standard deviations x is from μ. Then read the area from the cumulative table, which gives the area to the left of z.任何常態 x 都能轉換：z = (x − μ)/σ，表示 x 離 μ 幾個標準差。再查累積機率表，表上給的是 z 左邊的面積。

6.3 Exponential Probability Distribution指數機率分配

  • Describes the time until an event occurs or the time between events: time between arrivals at a car wash, time to load a truck, distance between defects on a road. In waiting-line applications it is often used for service time.描述事件發生前的等待時間或兩事件之間的時間：洗車場兩車抵達間隔、裝一台貨車的時間、路面兩個缺陷之間的距離。排隊問題常用它描述服務時間。
  • The mean and the standard deviation are equal (both μ). The distribution is skewed to the right, and its skewness is always 2.平均數＝標準差（都是 μ）。分配右偏，偏態永遠是 2。

P(x ≤ x₀) = 1 − e−x₀/μ　　P(x > x₀) = e−x₀/μ「下一位顧客 5 分鐘內到的機率」「收銀員 3 分鐘內服務完的機率」都是 P(x ≤ x₀)。

Relationship between the Poisson and Exponential Distributions卜瓦松與指數分配的關係

  • Same process, two questions. The Poisson (discrete) counts how many events occur in a fixed period; the exponential (continuous) measures how much time passes between two events.同一個過程問兩種問題：卜瓦松（離散）數一段時間內發生幾次；指數（連續）量兩次事件之間隔多久。
  • If arrivals are Poisson with a mean of λ per unit of time, the time between arrivals is exponential with mean 1/λ. Cars at a gas station arriving 20 per hour on average ↔ a mean of 60/20 = 3 minutes between cars (Alan's pump).若每單位時間平均 λ 次（卜瓦松），兩次之間的時間就是平均 1/λ 的指數分配。加油站平均每小時 20 輛車 ↔ 平均每 60/20 = 3 分鐘一輛（Alan 的例子）。
Chapter summarySummary 本章總結
  • For a continuous variable, probability = area under f(x); P(x = a) = 0 and the total area is 1.連續變數的機率＝f(x) 底下的面積；P(x = a) = 0，總面積 = 1。
  • Uniform: f(x) = 1/(b − a); probability = width × height; E = (a + b)/2, Var = (b − a)²/12.均勻：f(x) = 1/(b − a)；機率＝寬 × 高；E = (a + b)/2，Var = (b − a)²/12。
  • Normal: bell-shaped, symmetric, set by μ and σ; mean = median = mode; empirical rule 68.26 / 95.44 / 99.72%.常態：鐘形、對稱、由 μ 和 σ 決定；平均數＝中位數＝眾數；經驗法則 68.26 / 95.44 / 99.72%。
  • Standard normal: z = (x − μ)/σ; the table gives the area to the left; right tail = 1 − table; reverse look-up gives z, then x = μ + zσ.標準常態：z = (x − μ)/σ；表給左邊面積；右尾 = 1 − 查表值；反查得到 z 後 x = μ + zσ。
  • Exponential: time between events; P(x ≤ x₀) = 1 − e−x₀/μ; mean = σ = μ; right-skewed.指數：事件之間的時間；P(x ≤ x₀) = 1 − e−x₀/μ；平均數＝標準差＝μ；右偏。
  • Poisson λ per unit time ↔ exponential mean 1/λ between events.卜瓦松每單位時間 λ 次 ↔ 指數分配平均間隔 1/λ。
Common trap易錯點
  • The z-table gives the area to the left. For "more than" use 1 − table value (Pep Zone: 1 − 0.7967 = 0.2033, not 0.7967).z 表是左邊面積。「大於」要用 1 − 查表值（Pep Zone：1 − 0.7967 = 0.2033，不是 0.7967）。
  • Reverse look-up: a right tail of 0.05 means finding 0.95 inside the table, giving z = 1.645, not 0.05.反查：右尾 0.05 要在表格內找 0.95，得 z = 1.645。
  • Round a reorder point up (24.87 → 25); rounding down would let the stockout probability go above 5%.再訂購點要無條件進位（24.87 → 25），捨去會讓缺貨機率超過 5%。
  • For a continuous variable, P(x = a) = 0, and f(x) is a height, not a probability; ≤ and < give the same area.連續變數 P(x = a) = 0；f(x) 是高度不是機率；≤ 和 < 面積一樣。
  • Uniform variance divides by 12: (b − a)²/12, not (b − a)/12 or (b − a)²/2.均勻分配變異數除以 12：(b − a)²/12。
  • Exponential: P(x ≤ x₀) = 1 − e−x₀/μ uses the mean μ; if you are given a rate λ, the mean is 1/λ. Poisson counts (discrete), exponential measures time (continuous).指數：公式裡是平均數 μ；如果給的是發生率 λ，平均數是 1/λ。卜瓦松數次數（離散），指數量時間（連續）。
