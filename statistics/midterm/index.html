1.1 什麼是統計

  • 統計數據（numerical facts）：平均數、中位數、百分比、最大值等。
  • 統計學（art and science）：蒐集、分析、呈現、解釋資料的方法。

1.2 資料的基本名詞（期中必考，作業第 1 題）

名詞 英文 意思 例子（學生資料表）
資料集 data set 一項研究蒐集到的全部資料 整張表
元素 element 被蒐集資料的「對象」＝表格的列 每一位學生
變數 variable 元素的「特徵」＝表格的欄 年齡、主修、每週讀書時數
觀測值 observation 某一元素在所有變數上的量測結果＝一整列 「21 歲、資管、12 小時」
  • n 個元素 → n 個觀測值。
  • 資料值總數 ＝ 元素數 × 變數數。
  • 數元素時不要把表頭、名稱欄算進去；數變數時不要把「元素名稱欄」（例如平板型號）當成變數。

1.3 衡量尺度（Scales of Measurement）

由低到高，每一層都擁有前一層的性質：

尺度 能做什麼 特徵 例子
名目 Nominal 分類（＝, ≠） 只是標籤或代碼，沒有順序 學院別、作業系統、性別、郵遞區號
順序 Ordinal ＋排序（＜, ＞） 有順序，但間距沒意義 滿意度（差/普通/好）、名次、等第 A/B/C
區間 Interval ＋相減（間距有意義） 固定單位；沒有真正的 0（0 不代表「沒有」） 攝氏溫度、SAT 分數、年份
比率 Ratio ＋相除（比值有意義） 有真正的 0 價格、重量、時間、距離、電池續航時數

判斷口訣：

  1. 是標籤嗎？→ 是 → 有順序嗎？有＝順序，沒有＝名目。
  2. 是數值 → 「0」代表「完全沒有」嗎？是＝比率，否＝區間。
  3. 驗證比率：能不能說「A 是 B 的兩倍」？書價 200 元 vs 100 元可以 → 比率；20°C 不是 10°C 的「兩倍熱」→ 區間。

1.4 類別資料 vs 數量資料

類別資料 Categorical（質性 qualitative） 數量資料 Quantitative
問的問題 屬於哪一類？ 多少？幾個？
尺度 名目或順序 區間或比率
形式 可以是數字代碼或文字 一定是數字
算術運算 沒意義（代碼 1=管理、2=工程，不能平均） 有意義

1.5 橫斷面資料 vs 時間序列資料

  • 橫斷面（cross-sectional）：同一時間點、多個對象。例：2025 年 9 月台灣各縣市核發的建照數。
  • 時間序列（time series）：同一對象、多個時間點。例：台北市過去 36 個月每月建照數。用來看趨勢、預測。

1.6 資料來源

  • 既有資料：公司內部紀錄、商業資料庫、政府機關、產業公會、特殊團體、網路。
  • 統計研究
    • 觀察研究（observational）：不控制變數，例如問卷、吸菸者 vs 非吸菸者研究。
    • 實驗研究（experimental）：先確定目標變數，再控制其他變數，例如隨機對照試驗（RCT）。
  • 取得資料的考量：時間、成本、資料錯誤。

1.7 敘述統計 vs 推論統計

  • 敘述統計：用表格、圖形、數值摘要資料（例：Hudson Auto 50 張發票平均零件費 $79）。
  • 母體（population）：研究對象的全體；樣本（sample）：母體的子集合。
  • 普查（census）：調查整個母體；抽樣調查（sample survey）：只調查樣本。
  • 統計推論：用樣本資料去估計母體特徵或檢定假設。

1.8 Analytics（分析學）

  • 描述性分析：過去發生了什麼。
  • 預測性分析：用過去資料建模預測未來。
  • 處方性分析：給出最佳行動方案。

Ch2 表格與圖形

次數分配、長條圖與直方圖、偏態、累積分配、莖葉圖、交叉表與散佈圖。

2.1 類別資料的整理

  • 次數分配（frequency distribution）：每一類別有幾個。
  • 相對次數 ＝ 次數 ÷ 總數；百分比次數 ＝ 相對次數 × 100。
    • 為什麼要相對次數？Hotel A 20 則評價中 10 則 Excellent（50%），Hotel B 200 則中 50 則（25%）。只看次數會誤判。
  • 長條圖（bar chart）：類別資料，長條之間分開。
  • 圓餅圖（pie chart）：相對次數 × 360° ＝ 扇形角度（0.25 → 90°）。適合類別少、差異明顯、呈現「部分占整體」。

2.2 數量資料的整理

建立次數分配的三步驟：

  1. 決定組數：通常 5～20 組。
  2. 決定組距：組距 ≈（最大值 − 最小值）÷ 組數，取方便的整數。Hudson：（109 − 52）÷ 6 = 9.5 → 取 10。
  3. 決定組限：各組不重疊，且涵蓋所有資料。

圖形工具：

工具 用途 重點
點圖 Dot plot 數量資料全範圍分布 每個資料一個點

2.3 兩個變數：交叉表（Crosstabulation）

  • 兩變數可以是：類別＋類別、類別＋數量、數量＋數量（數量變數要先分組）。
  • 辛普森悖論（Simpson’s paradox）：分組資料的結論在合併（aggregated）後完全反轉。原因是存在隱藏變數（例如各組樣本數差很多）。看合併表前要先看分組表。

2.4 兩個變數：圖形

  • 散佈圖（scatter diagram）＋趨勢線：兩個數量變數的關係。正相關（讀書時數 vs 成績）、負相關（價格 vs 需求量）、無明顯關係（鞋碼 vs 成績）。
  • 群組長條圖（side-by-side）：比較各組之間的差異。
  • 堆疊長條圖（stacked）：看總量與組成；若用百分比，所有長條等高到 100%。

Chapter 3

Ch3 數值量數

平均數、中位數、眾數、幾何平均、百分位數、變異數與標準差、z 分數、柴比雪夫、盒鬚圖、相關係數。

  • 由樣本算出 → 統計量（statistic），例如 x̄、s；由母體算出 → 參數（parameter），例如 μ、σ。
  • 樣本統計量是母體參數的點估計量。

3.1 位置量數（Measures of Location）

量數 公式／算法 重點
平均數 x̄ = Σxᵢ / n；μ = Σxᵢ / N 受極端值影響大
中位數 排序後取中間；位置 (n+1)/2 n 為偶數取中間兩數平均；有極端值時優先使用（所得、房價）
眾數 出現最多次的值 可有兩個（雙峰）或更多（多峰）
加權平均數 x̄ = Σwᵢxᵢ / Σwᵢ GPA（學分為權重）、平均工資（工時為權重）
幾何平均數 x̄g = ⁿ√(x₁·x₂·…·xₙ) 用於成長率、報酬率等連乘／複利情況
百分位數 Lp = (p/100)(n+1) 見下方步驟
四分位數 Q1 = 第 25、Q2 = 第 50（中位數）、Q3 = 第 75 百分位數

幾何平均報酬率步驟

  1. 每期報酬率換成成長因子：1 + 報酬率（−10% → 0.90）。
  2. 全部相乘，開 n 次方根。
  3. 平均報酬率 ＝（幾何平均數 − 1）× 100%。

百分位數步驟（本課本的方法）

  1. 資料由小到大排序。
  2. 算位置 Lp = (p/100)(n+1)。
  3. Lp 是整數 → 直接取第 Lp 個值；有小數 → 第 i 個值 ＋ 小數部分 ×（第 i+1 個 − 第 i 個）。
    • 例：70 筆租金，80th：L = 0.8 × 71 = 56.8 → 635 + 0.8(649 − 635) = 646.2。
    • 例：Q3：L = 0.75 × 71 = 53.25 → 625 + 0.25(625 − 625) = 625。
  4. 解讀：「至少 p% 的資料 ≤ 此值，且至少 (100 − p)% 的資料 ≥ 此值」。

3.2 離散量數（Measures of Variability）

量數 公式 重點
全距 Range 最大值 − 最小值 最簡單，對極端值超敏感
四分位距 IQR Q3 − Q1 中間 50% 資料的範圍，不受極端值影響
樣本變異數 s² = Σ(xᵢ − x̄)² / (n − 1) 分母 n − 1（貝塞爾修正）
母體變異數 σ² = Σ(xᵢ − μ)² / N 分母 N
標準差 s = √s²；σ = √σ² 單位與原資料相同，比變異數好解釋
變異係數 CV (s / x̄) × 100%；(σ / μ) × 100% 相對變異程度，可跨不同單位或尺度比較
  • 貝塞爾修正：樣本資料離 x̄ 比離真正的 μ 近，用 n 會低估變異，所以除以 n − 1（自由度）。
  • CV 例子：A（平均 100，標準差 10）CV = 10%；B（平均 1000，標準差 50）CV = 5%。B 的標準差較大，但相對變異較小。

3.3 分布形狀、相對位置、離群值

  • 偏態：右偏 → 偏態係數 ＞ 0，平均數 ＞ 中位數；左偏 → ＜ 0，平均數 ＜ 中位數；高度偏態常 ＞ 1。
  • z 分數（標準化值）：zᵢ = (xᵢ − x̄) / s，代表「離平均數幾個標準差」。z ＜ 0 低於平均、z ＝ 0 等於平均、z ＞ 0 高於平均。
  • 柴比雪夫定理（Chebyshev’s theorem）：任何分布，至少 (1 − 1/z²) 的資料落在平均數 ± z 個標準差內（z ＞ 1，不必是整數）。
    • z = 2 → 至少 75%；z = 3 → 至少 88.89%（約 89%）；z = 4 → 至少 93.75%（約 94%）。
  • 經驗法則（Empirical rule）：鐘形（常態）分布才能用。±1σ 約 68%、±2σ 約 95%、±3σ 幾乎全部（99.7%）。
  • 離群值偵測
    • 方法一：|z| ＞ 3。
    • 方法二（盒鬚圖）：下限 ＝ Q1 − 1.5·IQR，上限 ＝ Q3 + 1.5·IQR；超出者為離群值。
    • 離群值可能是：記錄錯誤、不該放進資料集、或正確但特殊的值（不一定要刪）。

4.1 隨機實驗、樣本空間、計數法則

  • 機率：0 到 1 之間，越接近 1 越可能發生。
  • 隨機實驗：產生明確結果的過程，重複做結果可能不同。
  • 樣本空間 S：所有實驗結果的集合；每個結果叫樣本點。
  • 多步驟實驗計數法則：(n₁)(n₂)…(nₖ)。Bradley：Markley Oil 4 種 × Collins Mining 2 種 = 8 種結果。用樹狀圖表示。
  • 組合（順序不重要）：C(N, n) = N! / [n!(N − n)!]。例：從 5 人選 2 人組小組，Amy＋Ben ＝ Ben＋Amy。
  • 排列（順序重要）：P(N, n) = N! / (N − n)!。例：選隊長和副隊長。
  • 關係：P(N, n) = n! × C(N, n)。0! = 1。

4.2 指派機率

基本要求：(1) 0 ≤ P(Eᵢ) ≤ 1；(2) ΣP(Eᵢ) = 1。

方法 依據 例子
古典法 Classical 各結果等可能，每個 1/n 擲骰子每面 1/6
相對次數法 Relative frequency 實驗或歷史資料 Lucas 租機：40 天中 18 天租 2 台 → 0.45
主觀法 Subjective 判斷、經驗、專業 Bradley 投資分析師估計
  • 事件：樣本點的集合；事件機率 ＝ 其所含樣本點機率加總（Bradley：P(M) = 0.70、P(C) = 0.48）。

4.3 基本機率關係

關係 定義 公式
補集 Aᶜ 不在 A 的樣本點 P(Aᶜ) = 1 − P(A)
聯集 A ∪ B A 或 B 或兩者 加法律：P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
交集 A ∩ B A 且 B 乘法律：P(A ∩ B) = P(B)·P(A｜B) = P(A)·P(B｜A)
互斥 沒有共同樣本點 P(A ∩ B) = 0 → P(A ∪ B) = P(A) + P(B)
  • Bradley：P(M ∪ C) = 0.70 + 0.48 − 0.36 = 0.82。

4.4 條件機率與獨立

  • 條件機率：P(A｜B) = P(A ∩ B) / P(B)，「已知 B 發生，A 發生的機率」。
  • 聯合機率表：表格內部是聯合機率 P(A ∩ B)，邊緣（Total 列／欄）是邊際機率 P(A)、P(B)。
    • 從表求條件機率：P(A｜B) = 該格 ÷ B 那一列（或欄）的合計。
  • 獨立事件：P(A｜B) = P(A) 或 P(B｜A) = P(B)，等價於 P(A ∩ B) = P(A)·P(B)。
  • 互斥 ≠ 獨立：兩個機率都 ＞ 0 的事件，若互斥就一定不獨立（一個發生，另一個機率變 0）。

4.5 貝氏定理（Bayes’ Theorem）

  • 事前機率 P(Aᵢ) → 得到新資訊 B → 事後機率 P(Aᵢ｜B)。
  • 公式（兩事件）：P(A₁｜B) = P(A₁)P(B｜A₁) / [P(A₁)P(B｜A₁) + P(A₂)P(B｜A₂)]
  • 條件：A₁, A₂, … 互斥且聯集為整個樣本空間。
  • 分母就是全機率 P(B)。

一、第 1 章：資料分類

1. 元素 vs 變數 vs 觀測值

  • 元素＝列（對象，例如每台平板）；變數＝欄（特徵，例如價格）；觀測值＝一整列的數值。
  • 陷阱：表格第一欄「名稱／型號」是用來辨認元素的，不算變數。
  • 元素數＝觀測值數；資料值總數＝元素數 × 變數數。

2. 名目 vs 順序

  • 判斷：類別之間能不能排「好壞／大小」？能＝順序，不能＝名目。
  • 陷阱：用數字當代碼（1＝管理、2＝工程）仍是名目；名次 1、2、3 是順序。

3. 區間 vs 比率（最常錯）

  • 判斷：0 是不是「完全沒有」？能不能說「兩倍」？
  • 攝氏溫度 0°C 不是「沒有溫度」→ 區間；年份、SAT 分數 → 區間。
  • 價格、重量、時間、時數、距離、年齡、螢幕尺寸 → 比率。
  • 評分 0～100（如作業第 4 題外套評分）通常視為區間；考試若沒問就不用糾結。

4. 類別資料可以是數字嗎？

  • 可以。郵遞區號、學號、電話號碼、代碼 1/2/3 都是數字但屬類別資料，因為加減平均沒有意義。
  • 數量資料一定是數字；類別資料不一定不是數字。

5. 橫斷面 vs 時間序列

什麼是統計

  • 統計數據（numerical facts）：平均數、中位數、百分比；統計學：蒐集、分析、呈現、解釋資料的方法（art and science）。

資料的基本名詞（期中必考，作業第 1 題）

口訣

1.3

衡量尺度（Scales of Measurement）

口訣
  • 「名、序、區、比」，每一層都有前一層的性質
  • Nominal 只是標籤（郵遞區號、作業系統）；Ordinal 有順序但間距沒意義（滿意度、名次）；Interval 間距有意義、沒有真正的 0（攝氏、SAT、年份）；Ratio 有真正的 0（價格、時間、續航）。

1.4

類別資料 vs 數量資料

  • 類別資料（qualitative）：名目或順序，可以是數字代碼，但算術沒意義（代碼不能平均）。
  • 數量資料：區間或比率，一定是數字，可以做算術，分析方法較多。
1.5

橫斷面資料 vs 時間序列資料

  • 橫斷面：同一時間、多個對象（2025 年 9 月各縣市建照數）。時間序列：同一對象、多個時間點（台北 36 個月建照數），看趨勢、預測。
1.6

資料來源

  • 既有資料：內部紀錄、商業資料庫、政府、公會、網路。
  • 觀察研究：不控制變數（問卷、吸菸者 vs 非吸菸者）；實驗研究：控制其他變數（RCT）。考量：時間、成本、資料錯誤。
1.7

敘述統計 vs 推論統計

  • 敘述統計：用表、圖、數值摘要資料。統計推論：用樣本估計母體特徵或檢定假設。
  • 母體 population vs 樣本 sample；普查 census vs 抽樣調查 sample survey。
1.8

Analytics（分析學）

  • 描述性（過去發生什麼）→ 預測性（建模預測未來）→ 處方性（給最佳行動方案）。

Ch2 表格與圖形

2.1

類別資料的整理

  • 相對次數 = 次數 ÷ 總數；百分比 = 相對次數 × 100。只看次數會誤判：A 20 則中 10 則（50%）比 B 200 則中 50 則（25%）好。
  • 長條圖：類別資料、長條分開。圓餅圖：相對次數 × 360°（0.25 → 90°），適合類別少、看部分占整體。
2.2

數量資料的整理

口訣
  • 三步驟：「組數 5～20 → 組距 ≈ (最大 − 最小) ÷ 組數取整 → 組限不重疊、全涵蓋」
  • Hudson：(109 − 52) ÷ 6 = 9.5 → 組距取 10。累積次數以各組上限累加（≤59、≤69…），累積相對次數 = 累積次數 ÷ n。
  • 直方圖長條相連；點圖、莖葉圖保留原始資料。
  • 偏態看尾巴：右偏（所得、課金）平均 > 中位；左偏（簡單考試）平均 < 中位；對稱相等。
  • 莖葉圖葉單位：1682 用葉單位 10 → 莖 16、葉 8（捨去不是四捨五入）；伸展莖葉圖每個莖寫兩次（0～4、5～9）。
2.3

兩個變數：交叉表（Crosstabulation）

  • 交叉表：類別＋類別、類別＋數量、數量＋數量（數量要先分組）。
  • 辛普森悖論：分組的結論在合併後反轉，原因是隱藏變數（各組樣本數差很多）→ 先看分組表。
2.4

兩個變數：圖形

  • 散佈圖＋趨勢線：兩個數量變數（正、負、無關係）。
  • 群組長條圖：比較各組差異；堆疊長條圖：看總量與組成，用百分比時每條都等高到 100%。
2.5

圖形選擇總表

  • 分布：類別 → 長條、圓餅；數量 → 點圖、直方圖、莖葉圖。比較 → 群組／堆疊長條圖。關係 → 散佈圖＋趨勢線。
  • Dashboard：呈現 KPI；減少捲動、不要多餘顏色或 3D、用框線分隔。

Ch3 數值量數

3.1

位置量數（Measures of Location）

口訣
  • 百分位數：「排序 → L = (p/100)(n+1) → 整數直接取，有小數就內插」
  • 平均數受極端值影響大；有極端值（所得、房價）用中位數；眾數可以雙峰、多峰。
  • 加權平均 Σwx ÷ Σw（GPA、平均工資：5 種工資直接平均是錯的）。
  • 幾何平均：報酬率換成 1 + r（−10% → 0.90），全部相乘開 n 次方，再 −1。
  • 70 筆租金 80th：L = 0.8 × 71 = 56.8 → 635 + 0.8(649 − 635) = 646.2。Q1、Q2、Q3 = 第 25、50、75 百分位數。
3.2

離散量數（Measures of Variability）

  • 全距 = 最大 − 最小（對極端值超敏感）；IQR = Q3 − Q1（不受極端值影響）。
  • 樣本變異數 s² 分母 n − 1（用 x̄ 會低估變異）；母體 σ² 分母 N；標準差單位和原資料相同。
  • CV = s / x̄ × 100%，跨單位比較：A（100, 10）10%、B（1000, 50）5% → B 相對變異較小。
3.3

分布形狀、相對位置、離群值

口訣
  • 「方向看尾巴，平均數跟著尾巴跑」
  • z = (x − x̄) / s：離平均幾個標準差。
  • 柴比雪夫（任何分布）：至少 1 − 1/z²：z = 2 → 75%、z = 3 → 88.89%、z = 4 → 93.75%。
  • 經驗法則（只有鐘形）：68%、95%、99.7%。分布未知只能用柴比雪夫。
  • 離群值：|z| > 3，或超出 Q1 − 1.5·IQR、Q3 + 1.5·IQR；不一定要刪。
3.4

五數摘要與盒鬚圖

  • 五數摘要：最小、Q1、中位數、Q3、最大。
  • 盒鬚圖：盒子 Q1～Q3、中間一線是中位數；上下限只定位不畫；鬚線到限內的最小最大值；離群值標 *。
  • 租金：Q1 545、Q3 625、IQR 80 → 下限 425、上限 745。
3.5

兩變數的關聯

  • 共變異數 sxy = Σ(x − x̄)(y − ȳ) / (n − 1)：只看方向，受單位影響。
  • 相關係數 r = sxy / (sx·sy)：−1～+1、無單位，看方向和強度。
  • 只衡量線性關係；相關不等於因果。高爾夫：距離越遠桿數越低 → r ≈ −0.96。

Ch4 機率導論

4.1

隨機實驗、樣本空間、計數法則

  • 樣本空間 S：所有實驗結果；每個結果是樣本點。
  • 多步驟計數：n₁ × n₂ × …（Bradley 4 × 2 = 8，用樹狀圖）。
  • 組合（順序不重要）C(N, n) = N! / [n!(N − n)!]；排列（順序重要）P(N, n) = N! / (N − n)!；P = n! × C；0! = 1。
4.2

指派機率

  • 兩個要求：0 ≤ P ≤ 1、全部加起來 = 1。
  • 古典法（等可能，骰子 1/6）、相對次數法（Lucas：40 天中 18 天 → 0.45）、主觀法（專家判斷）。
  • 事件機率 = 它所含樣本點機率加總。
4.3

基本機率關係

  • 補集 P(Aᶜ) = 1 − P(A)。
  • 加法律 P(A ∪ B) = P(A) + P(B) − P(A ∩ B)；Bradley：0.70 + 0.48 − 0.36 = 0.82。
  • 互斥 → P(A ∩ B) = 0 → 直接相加。乘法律 P(A ∩ B) = P(B)·P(A｜B)。
4.4

條件機率與獨立

  • P(A｜B) = P(A ∩ B) / P(B)；從聯合機率表算：該格 ÷ B 那一列（欄）的合計。
  • 表內是聯合機率，邊緣是邊際機率。
  • 獨立：P(A｜B) = P(A)，等價 P(A ∩ B) = P(A)P(B)。
  • 互斥 ≠ 獨立：兩個機率都 > 0 的互斥事件一定不獨立。
4.5

貝氏定理（Bayes’ Theorem）

口訣
  • 表格五欄：「事件、事前、條件、聯合 = 事前 × 條件、事後 = 聯合 ÷ 合計」
  • 事前 P(Aᵢ) → 新資訊 B → 事後 P(Aᵢ｜B)；分母是全機率 P(B)；Aᵢ 必須互斥且聯集為全部。
  • 例：0.7 × 0.2 = 0.14、0.3 × 0.9 = 0.27 → P(B) = 0.41 → 事後 0.3415、0.6585。條件那一欄加起來不必是 1。
  • 作業 9：事前 0.02、P(+｜C) 0.8、偽陽性 0.75 → P(C｜+) = 0.016 / 0.751 ≈ 0.021。
