# TOEIC 金色計畫 (`toeic/`)

Daily course from ~550 to 990: about 30 minutes a day. Each topic in `TOEIC_COURSE` is split over two days (handout and
the first half of its words and questions, then the second half), so the course runs 40 weeks; day 7 of each week is a review.
Hand-written pages, not generated: edit the data files directly.

- `data/course.js`: `TOEIC_COURSE.weeks` (the roadmap, `[topic, Part, vocab theme]` per day) and `TOEIC_DAYS[n]`
  (hand-written content for topic n = (topic week-1)*7 + topic number 1–6). A day without hand-written content is generated by AI
  (Gemini through the Worker, needs sign-in) the first time it is opened and saved to the account (`toeic-ai-v1`).
- `data/mocks.js`: built-in mini mock tests. **Add a mock by pushing a new object at the end** with a new `id`;
  never change an existing id (scores are stored by id). The page can also ask AI for more mocks, without limit.
- `app.js`: the page. Progress is in localStorage `toeic-v1` (synced by `ezsync.js`, merged record by record by `t`).

## Item formats

```js
{p:5, q:"sentence with ____", o:[4 options], a:0, e:"繁中解析"}            // Part 5
{p:2, say:"question", o:[3 responses], a:1, e:"..."}                      // Part 2 (read aloud, options hidden until answered)
{p:1, scene:"照片情境", o:[4 statements], a:2, e:"..."}                     // Part 1 (no photos: a described scene)
{p:3, talk:[["M","line"],["W","line"]], qs:[{q,o:[4],a,e}, ...]}          // Part 3 (M, W, M2, W2 voices) / Part 4 (one speaker)
{p:6, text:"... ___(1)___ ...", qs:[{q:"(1)",o,a,e}, ...]}                 // Part 6
{p:7, text:"passage\nwith line breaks", qs:[{q,o,a,e}, ...]}               // Part 7
```

Listening uses the browser's speech synthesis (Edge/Chrome voices sound best). Scores are an accuracy-based estimate.
All questions are original TOEIC-style practice, not ETS material.
