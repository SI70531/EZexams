Structure 2Doubly linked listSlide 95 to 97雙向鏈結串列

  • One of the most powerful variations of linked lists. Each node has two pointers: one to its successor and the other to its predecessor.鏈結串列最強大的變形之一。每個節點有兩個指標：一個指向後繼者，一個指向前一個。

  • The same set of data can be processed in multiple sequences. The data are not replicated: the data exist only once, but multiple paths connect the one set of data.同一份資料可以依不同順序處理。資料不複製：只存一份，用多條路徑連起來。
  • To process the data in multiple sequences, create a separate set of links for each sequence. Each link structure can be singly linked, doubly linked, or circularly linked.要用多種順序處理，就為每種順序建一組獨立的 link。每組 link 可以是單向、雙向或環狀。

Common trap易錯點
  • append's loop is pLoc->link not null (stop on the last node), and the count is list1.count + list2.count.append 的迴圈是 pLoc->link not null（停在最後一個節點上），count 是兩者相加。
  • The first call to getNext uses fromWhere 0; later calls use 1.第一次呼叫 getNext 的 fromWhere 是 0，之後是 1。
  • insertDbl returns 0 / 1 / 2 = memory full / success / duplicate key. Use the corrected version: pPre->fore = pNew is in the else part (4.4.3), and line 4.6 is if (pSucc null).insertDbl 回傳 0／1／2 = 記憶體滿／成功／重複。用修正版：pPre->fore = pNew 在 else 裡（4.4.3），4.6 行是 if (pSucc null)。
  • Inserting into a doubly list in the middle changes four pointers; at the end, update rear; before the first node, update head.雙向串列插在中間要改四個指標；插在尾端要改 rear；插在第一個之前要改 head。
  • deleteDbl: back null → change head; fore null → change rear. It aborts on a null pDlt; the search is done by the caller.deleteDbl：back 是 null 改 head；fore 是 null 改 rear。pDlt 是 null 就中止；搜尋由呼叫者做。
  • Circular search: when the target does not exist, stop when pLoc->link equals the saved startAddress, or the loop never ends.環狀搜尋：target 不存在時，pLoc->link 等於存下來的 startAddress 就要停，否則會無限迴圈。
  • Multilinked lists do not copy the data; memory is allocated once and the count is added once.多重鏈結串列不複製資料；記憶體只配置一次，count 只加一次。
